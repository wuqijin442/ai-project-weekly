## 实现要点（`src/rag_lib.py` / `rag_index.py` / `learn_link.py`）

- `rag_lib.EXTRA_CORPORA`：指向 DGX 磁盘 `/opt/ragkb/extra/obsidian`、`/opt/ragkb/extra/energy`（两库由本机 scp 预置，只读磁盘、不走 git，故不依赖仓库同步）。
- 新增 `_iter_extra_corpora()`：遍历配置目录、按扩展名分块（md→`chunk_markdown` / json→`chunk_text`），source 形如 `obsidian/...md#i`、`energy/...md#i`，与 git 源命名一致。
- 新增 `existing_source_prefixes(col)`：取集合中已有 source 并去掉 `#块序号` 得"文件前缀"，供**增量按文件跳过**。
- `rag_index.py`：默认=**增量**（过滤已在库文件，仅插新）；`--force`=一次性全量重建（drop+rebuild）。
- `learn_link.rag_ingest()`：去掉 `--force`，改走增量（每日仅追加新知识，知识库滚动自进化）。
