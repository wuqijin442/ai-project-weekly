## 5. 开放问题 / 值得关注的风险

1. **Kronos 实测 failed**：克隆或运行阶段报错（日志未附具体信息），需确认是网络问题还是项目本身构建链不完整；若为后者，其"基础模型"定位的落地成熟度存疑。
2. **claude-mem 的隐私边界**：跨会话持久化"Agent 做的一切"，涉及用户行为日志的存储位置、加密策略、多租户隔离——README 中未见明确安全模型说明，生产使用前需审计。
3. **lightpanda 的生态风险**：Zig 语言工具链仍处 0.x 阶段，依赖生态薄；"AI 专用浏览器"若无法覆盖足够多的 Web 标准（Canvas、WebGL、复杂 CSS），实际可用性受限。
4. **样本偏小**：今日仅 5 个项目，且 4/5 归入 AI/LLM/Agent 类别，可能反映采集工具的分类权重偏向，未必代表全市场热度分布；建议结合 Trending 全量数据交叉验证。
5. **public-apis 的"信息密度衰减"**：star 持续增长但项目本质是链接列表，对 AI 应用的实际价值取决于"有多少 API 真正可用且免费"；需关注其维护频率与 API 存活率。
