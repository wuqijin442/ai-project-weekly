3. **样本量有限**：今日仅 5 个项目，类别覆盖虽广但每类仅 1 个代表，难以判断趋势的统计显著性；建议连续 3-5 日观察后再做方向性结论。
4. **AI Agent 安全边界**：rea 将 Agent 能力用于逆向，若 Agent 被恶意 prompt 注入或目标系统存在漏洞，可能产生非预期行为；其沙箱隔离机制值得重点审查。
5. **前端渲染真实数据的性能天花板**：gods-eye-view 在浏览器中消费实时卫星数据，数据量增长后 WebGL 渲染与 JS 主线程的瓶颈将显现；需关注其是否引入 Web Worker / WASM 加速。
