# gpt-engineer-org/gpt-engineer

> 从自然语言提示词一键生成完整代码仓库

## 项目定位

GPT Engineer 是 Vibe Coding 赛道的早期明星项目，核心能力是**从一句自然语言描述生成完整代码仓库**（含多个文件、依赖配置、README 等）。支持后续迭代修改，开发者可通过对话不断完善项目。

## 技术栈

- **语言**：Python
- **LLM 支持**：OpenAI GPT-4、Anthropic Claude、本地模型
- **核心能力**：全仓库生成、对话式迭代、代码执行
