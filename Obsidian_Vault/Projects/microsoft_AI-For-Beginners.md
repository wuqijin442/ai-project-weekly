## 项目定位

微软官方出品的 **AI 入门课程**：**12 周 24 课**，口号是 "AI for All"。定位在「零基础到能读懂现代 AI」，不是速成班也不是论文导读。

## 课程覆盖

**会讲的**：

- **符号 AI（GOFAI）**：知识表示与推理——现在很少有课程还认真讲这块
- **神经网络与深度学习**：核心内容，同时给出 **TensorFlow 与 PyTorch 两套代码**
- **图像与文本的神经架构**：CNN / RNN / GAN 等（README 坦承在 SOTA 覆盖上有滞后）
- **冷门路径**：遗传算法、多智能体系统

**明确不讲的**（README 直接列出并给了替代资源）：

- AI 商业案例 → Microsoft Learn 商业路径
- 经典机器学习 → 姊妹课程 ML-for-Beginners
- Cognitive Services 实战应用
- Azure ML / Fabric / Databricks 等云框架
- 对话式 AI 与聊天机器人
- 深度学习背后的深层数学 → 推荐 Goodfellow《Deep Learning》

**这份「不讲清单」本身就是这门课的质量信号**：范围收得住，不假装什么都覆盖。

## 每课结构

每节课包含课前/课后测验、书面讲义、可运行的 Notebook（PyTorch / Keras / TensorFlow 三选）以及配套 Lab。

## 多语言支持

通过 GitHub Action 自动翻译并保持同步，覆盖 **50+ 语言**，含**简体中文、繁体中文（台湾 / 香港 / 澳门）**。
