## 项目定位

👁️ **给 AI Agent 一键装上互联网能力**——一个 CLI 打通主流内容平台的读取与搜索，**零 API 费用**。

项目切中的痛点非常具体：AI Agent 已能写代码、改文档、管项目，但一让它上网找东西就抓瞎——

- YouTube 教程拿不到字幕
- Twitter 搜索要付费 API
- Reddit 直接 403（服务器 IP 被拒）
- 小红书必须登录才能看
- B 站视频拿不到内容

Agent Reach 的主张是「**当下最稳的接入方式，替你选好、装好、体检好**」：接入方式会换代，由项目侧持续兜底，使用方不用操心。
