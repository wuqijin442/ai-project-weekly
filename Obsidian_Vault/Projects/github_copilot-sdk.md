## 项目定位

GitHub 官方出品的**多平台 SDK**，用于将 **GitHub Copilot Agent** 集成进各类应用与服务，把「编码 Agent 能力」标准化为可调用的基础设施。支持 Dotnet / Go / Java / Nodejs / Python / Rust 多语言，通过客户端全局 RPC（如 hooks.invoke）对接 Copilot CLI。

## 技术栈

- 语言：多平台 SDK，核心 Java（MR-JAR 适配 JDK 25 虚拟线程）
- 分发：Dotnet / Go / Java / Nodejs / Python / Rust 各语言客户端
- 集成：统一 hooks 路由、agentic 工作流、组织计费支持
- 定位：Copilot Agent 嵌入 SDK
