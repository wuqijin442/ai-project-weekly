## 项目定位

**面向 AI Agent 的图原生上下文基础设施**——自号「AI Agent 的开源 Palantir」。把企业数据 ingestion 进来，抽取关键要素，构建**上下文图（Context Graph）+ 知识图谱（KG）**，再叠加图分析与因果推理，且**全程带决策溯源（provenance）**。一句话：让 Agent「依据什么事实做决定」这件事变得可解释、可追踪、可审计。

核心卖点：可解释、可追溯、可信（Explainable, traceable, trustworthy by design）；自托管、可审计、受治理、零厂商锁定。

## 核心能力

- **Decision Intelligence**：决策智能
- **Context Management**：上下文管理（上下文图是核心资产）
- **Deterministic Reasoning**：确定性推理
- **Ontology Management**：本体管理
- **Knowledge Modeling**：知识建模
- **End-to-End Traceability**：端到端溯源

## 技术栈

- **存储**：多语言图存储（Polyglot Graph Storage），支持 **RDF + LPG** 两种图模型
- **标准**：W3C 标准，强调互操作
- **分析**：图分析 + 因果推理（causal reasoning）
- **分发**：PyPI（`semantica`）+ pip 安装；Python 3.8+
- **定位**：AI Agent 的上下文/知识底座（developer-tools + context-engineering）
