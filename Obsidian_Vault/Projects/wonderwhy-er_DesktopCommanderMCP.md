## 项目定位

一个**为 Claude 等 AI 提供终端控制、文件系统检索与差异（diff）编辑能力**的 MCP 服务器。让 AI 能够搜索、更新、管理文件并运行终端命令，自动化处理代码与文本任务，能力远超普通 AI 编辑器，且复用宿主客户端订阅而非消耗 API token。另提供 Desktop Commander App（Beta），可使用任意 AI 模型（Claude、GPT-4.5、Gemini 2.5 等）。

## 技术栈

- 语言：TypeScript；以 npm 包 `@wonderwhy-er/desktop-commander` 分发
- 协议：MCP（Model Context Protocol）
- 能力：终端执行、文件检索/编辑、diff 文件修改、进程管理
- 扩展：可作为 Gemini CLI 扩展；提供独立桌面 App
