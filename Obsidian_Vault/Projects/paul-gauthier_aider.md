# paul-gauthier/aider

> 终端 AI 结对编程工具，支持 Git 集成与多文件编辑

## 项目定位

Aider 是一款在终端中运行的 AI 结对编程工具，最大特色是**深度 Git 集成**——每次 AI 修改代码后自动生成合理的 Git commit 信息。支持多文件协同编辑，可直接在命令行中与代码库对话。

## 技术栈

- **语言**：Python
- **LLM 支持**：GPT-4、Claude、本地模型
- **核心能力**：多文件编辑、自动 Git commit、代码库语义搜索
