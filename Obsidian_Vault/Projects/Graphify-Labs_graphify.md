## 项目定位

一个**面向 AI 编码 Agent 的技能（skill）**，核心卖点：把任意目录下的代码、SQL schema、R 脚本、Shell 脚本、文档、论文、图片或视频，**统一构建成一张可查询的知识图谱**——应用代码 + 数据库 schema + 基础设施同处一张图。让 Claude Code、Codex、OpenCode、Cursor、Gemini CLI 等编码 Agent 在理解仓库时更省 token、调用工具更少，检索与推理从「全文扫描」升级为「图查询」。

- 语言：Python
- 图谱 / 检索：GraphRAG、knowledge-graph、RAG
