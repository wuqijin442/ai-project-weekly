## 项目定位

**Agentic 自托管可视化 CMS / 建站工具**，对标 Webflow、Framer、WordPress。一个 Bun 服务内集成可视化编辑器、内容引擎、媒体、鉴权、表单、插件与发布器；核心是「Agentic」——AI 直接生成干净语义化 HTML + 紧凑 CSS，页面不含框架运行时 / 构建器残留属性（无 div soup），多数情况直接作为静态文件加载。一句话：把 Vibe Coding 范式带入可视化建站，让 Agent 产出可生产、可读源码的站点。

## 技术栈

- **形态**：自托管可视化 CMS（MIT 许可），单一 Bun 服务承载编辑器/内容/发布全链路
- **运行**：Bun 运行时 + TypeScript；数据层 SQLite 或 Postgres
- **输出**：纯净语义 HTML + 紧凑 CSS，无框架运行时、无 builder 属性
- **能力**：画布编辑器、内容引擎、媒体/表单/插件系统、一键部署
- **Topics**：cms, css, page-builder, static, website
