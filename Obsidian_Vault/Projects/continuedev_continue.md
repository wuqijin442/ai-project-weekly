# continuedev/continue

> open-source coding agent

## 项目定位

Continue 是一款开源的 AI 编程助手，支持 **VS Code 和 JetBrains** IDE 插件模式。核心定位是**开发者完全掌控 AI 工具链**——支持任意 LLM（云端或本地），所有对话和数据可审计，是 Cursor 的最成熟开源替代方案。

## 技术栈

- **语言**：TypeScript（IDE 插件）+ Python（服务端）
- **IDE 支持**：VS Code、JetBrains 全系列

- **核心能力**：对话式编码、代码库 RAG、自定义 Prompt 模板、本地模型优先
