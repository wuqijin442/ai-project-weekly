## 项目定位

编码 Agent **pi** 的本地 Web UI。读取本地 pi 会话文件，在浏览器中提供会话浏览、实时聊天、模型配置、技能管理与项目文件预览的工作区；让同一段 pi 会话在 CLI 之外以结构化 Markdown、可读工具调用与项目导航的形式呈现。一句话：把「终端编码 Agent」的会话与配置搬到浏览器，降低 Vibe Coding 的可观测与协作门槛。

## 技术栈

- **形态**：本地 Web UI（编码 Agent 会话浏览器 / 工作台）
- **运行**：`npx @agegr/pi-web@latest` 或全局 `npm i -g @agegr/pi-web` 后 `pi-web`，默认 `http://localhost:30141`
- **关联 Agent**：[pi coding agent](https://github.com/badlogic/pi-mono)（badlogic/pi-mono）
- **能力**：会话浏览、实时聊天、模型配置、技能管理、项目文件预览、HTTP/HTTPS 代理环境变量支持
- **语言/运行时**：TypeScript（前端 + 本地 Node 服务）
