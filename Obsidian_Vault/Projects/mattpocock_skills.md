## 项目定位

Matt Pocock（Total TypeScript 作者）日常在真实工程中使用的 **AI Agent 技能集**，定位「为真实工程师服务，而非 vibe coding」。强调技能**小而可组合、跨模型通用**，基于数十年工程经验沉淀；与 GSD / BMAD / Spec-Kit 等「接管流程」方案不同，这些技能保留开发者控制权，便于 hack 与改造。安装：`npx skills@latest add mattpocock/skills`。
