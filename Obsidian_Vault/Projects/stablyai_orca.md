## 项目定位

Orca 是面向「**并行 Agent 舰队**」的 AI 开发环境（ADE，Agent Development Environment）。桌面 + 移动端可用，让你用**自己的订阅**跑任意编码 Agent（Claude Code / Codex / Cursor / OpenCode），支持 worktrees、终端、编排多 Agent 并行工作。YC 背景团队出品。
