## 项目定位

让网站对 AI 代理「可读、可操作」。browser-use 把任意网页抽象成 Agent 可交互的环境，配合 Playwright 驱动真实浏览器，完成表单填写、点击、信息抽取等自动化任务——是 Vibe Coding / Agentic Web 操作层的代表项目。

## 技术栈

- 语言：Python
- 底层：Playwright（浏览器自动化）
- 集成：LLM Agent 工具调用（Function Calling）、MCP
