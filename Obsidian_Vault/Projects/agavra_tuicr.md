## 项目定位

`tuicr` 是一个**带 vim 键绑定的代码审查 TUI（终端 UI）**，把 AI 辅助 code review 搬进终端。它让开发者在熟悉的 vim 风格交互中浏览差异、查看 AI 审查意见，将"代码质量"环节直接接入日常终端工作流。

## 核心能力

- **vim 键位**：沿用 vim 键绑定的终端交互，低上手成本
- **AI 辅助审查**：在 TUI 内呈现代码审查建议
- **终端原生**：无需离开终端即可完成 review 流程
