## 项目定位

**编码 Agent 的极简 Web GUI**。为多个编码 Agent 提供统一可视化界面：当前支持 Codex、Claude Code、Cursor CLI、OpenCode，后续扩展。用户安装并鉴权至少一个 provider 后即可在浏览器中驱动 Agent 写代码；也可 `npx t3@latest` 免安装运行或下载桌面端。一句话：把分散的编码 Agent（Codex/Claude/Cursor/OpenCode）收口到一个轻量 Web 控制台，是 Vibe Coding 的统一入口层。
