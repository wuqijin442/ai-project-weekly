## 项目定位

Google 官方维护的 **Agent Skills** 仓库，覆盖 Google 自家产品与技术栈（重点是 **Google Cloud**）。README 明确标注「**under active development**」。

它的意义不在技能数量，而在**身份**：此前技能层的头部全是个人开发者——mattpocock、addyosmani、obra——**Google 是第一个带着完整产品线正式下场的大厂**。

## 安装

```bash
npx skills add google/skills
```

安装时可从仓库中**按需勾选**具体技能，不必全量拉取。

## 技能分类（节选）

- **Google Cloud 入门**：认证鉴权、Foundation Builder、Onboarding 配方
- **多产品解决方案**：
  - Google Cloud 解决方案架构工作流
  - 跨云 / 跨数据类型的 Agentic 分析（Spark + Knowledge Catalog）
  - 无边界开放数据湖仓 Agentic AI 系统
  - 在 Google Cloud 上构建与部署 AI Agent
  - Agent 驱动的数据科学工作流
  - 实时双向多模态流式 Agentic AI
  - 迁移 AI 负载到 GKE Inference
  - 企业检索 RAG

## 竞争格局的含义

技能库的竞争逻辑会因此分裂成两条线：

| | 社区库 | 厂商库 |
| --- | --- | --- |
| 代表 | mattpocock/skills、obra/superpowers、addyosmani/agent-skills | **google/skills** |
| 卖点 | 通用工程手艺 | **我家产品只有我最懂** |
| 护城河 | 工程品味（可被更好的模型抹平） | 产品线独家知识（不可替代） |

两条线不冲突，但会让「装哪些技能」从审美问题变成**供应链问题**。
