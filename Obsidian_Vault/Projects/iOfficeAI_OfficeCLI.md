## 项目定位

全球**首个专为 AI Agent 打造的 Office 套件**，让任意 AI Agent 一行代码读取、编辑、自动化 Word / Excel / PowerPoint。开源、单二进制、无需安装 Office。内置 HTML 渲染引擎将 docx / xlsx / pptx 高保真渲染为 HTML / PNG，为 Agent 提供「眼睛」，形成 render → look → fix 的闭环。
