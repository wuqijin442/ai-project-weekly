## 项目定位

精选的 **DESIGN.md 合集**（已收录 73 个），从真实开发者向网站中提炼设计系统文档。把一份 DESIGN.md 放进项目，告诉 AI Agent「照这个样子帮我做个页面」，即可生成视觉高度一致的 UI。DESIGN.md 是 Google Stitch 提出的新概念——一份纯文本设计系统文档，AI 编码 Agent 或 Google Stitch 读取后即理解项目应有的视觉语言。仓库强调"真实设计深度"（分析过的 patterns、tokens、rules），产出高质量 UI 而非表面效果。

## 核心特点

- **即放即用**：DESIGN.md 是普通 Markdown，无需 Figma 导出、无 JSON Schema、无特殊工具
- **Agent 友好**：Markdown 是 LLM 最易读的格式，无需解析或配置
- **与 AGENTS.md 互补**：AGENTS.md 告诉编码 Agent 如何构建项目，DESIGN.md 告诉设计 Agent 项目应如何呈现
- **持续扩充**：支持按网站请求新的 DESIGN.md（含私有请求）
