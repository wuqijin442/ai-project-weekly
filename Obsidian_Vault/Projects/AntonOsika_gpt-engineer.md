# AntonOsika/gpt-engineer

> CLI platform to experiment with codegen. Precursor to: https://lovable.dev

## 项目定位

GPT Engineer 是 Vibe Coding 赛道的早期明星项目，核心能力是**从一句自然语言描述生成完整代码仓库**（含多个文件、依赖配置、README 等）。作者 Anton Osika 后续基于此项目创立了 Lovable.dev（商业化产品）。
