## 项目定位

本地优先（local-first）的 **AI 编码 Agent 联网研究与检索工具**。通过 MCP 为编码 Agent 提供搜索、抓取、爬取与检索（search / fetch / crawl / research）能力，让 Agent 在不依赖云端 API、零查询成本的前提下完成网页研究。主打隐私优先、无 API key、$0/query，Public beta。

一句话：「你的 AI 编码 Agent 的本地上网入口」——把 web search 做成 Agent 可调用、可审计、不泄露上下文的 MCP 服务。原生对接 **Claude Code · Cursor · Codex · Gemini CLI · VS Code · Windsurf · Zed · Antigravity**，以及 LangChain · CrewAI · LlamaIndex · Vercel AI SDK · n8n 与任意 MCP client。

## 技术栈

- **语言/运行时**：TypeScript / Node.js（metasearch 引擎）
- **集成**：MCP server（model-context-protocol），直接对接 Claude 等编码 Agent
- **能力**：web-search（聚合搜索）、web-scraping / web-crawler（抓取与爬取）、RAG 检索
- **架构**：local-first（本地运行，无云依赖），privacy 优先
