## 项目定位

🌟 **The Multi-Agent Framework: First AI Software Company, Towards Natural Language Programming.**

MetaGPT 把一个软件公司的工作流压缩进多智能体协作：产品经理、架构师、工程师、QA 等角色由不同 Agent 扮演，输入一句自然语言需求，输出完整的项目仓库（文档 + 代码 + 测试用例）。是「自然语言编程 / 多智能体自动化软件开发」赛道的奠基性开源项目。

## 核心机制

- **SOP 编码化**：把人类软件团队的 Standard Operating Procedure 固化为 Agent 协作流水线
- **角色分工**：Product Manager → Architect → Engineer → QA → … 各自产出标准化工件
- **产物链**：用户故事 → 需求文档 → 系统设计 → 接口定义 → 代码 → 测试
