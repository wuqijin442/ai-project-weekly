# cognee

> 开源 AI 记忆平台 — 为 Agent 提供跨会话持久长期记忆

## 🎯 项目定位

专为 AI Agent 设计的开源记忆平台，通过自托管知识图谱引擎为 AI Agent 提供跨会话持久长期记忆，解决 Agent 的"记忆遗忘"痛点。

**核心价值**：
- 持久化长期记忆：跨会话保持记忆连续性
- 自托管知识图谱引擎：数据自主可控
- 面向 Agent 架构：定位为 AI Agent 基础设施层

**模块化架构**：
- cognee（核心）、cognee-mcp（MCP 协议集成）、cognee-frontend（可视化前端）、cognee-starter-kit（快速启动套件）

## 🛠 技术栈

- **Python** — 核心引擎
- **TypeScript/Next.js** — 前端可视化
- 多数据库：Kuzu（图数据库）、Neo4j、pgvector、Redis
- 多模型：OpenAI、Ollama、LiteLLM
- 多平台部署：Docker、Modal、Railway、Fly.io
- OpenTelemetry 可观测性
