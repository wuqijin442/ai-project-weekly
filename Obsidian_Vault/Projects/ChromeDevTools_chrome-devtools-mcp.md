## 项目定位

`chrome-devtools-mcp` 是**面向 coding agents 的 Chrome DevTools MCP 服务器**——把浏览器调试能力（基于 puppeteer / Chrome DevTools Protocol）通过 MCP 协议带给 AI 编码 Agent，让 Agent 能直接驱动浏览器、排查前端问题、读取运行时状态。

## 核心能力

- **浏览器调试 MCP**：以标准化 MCP 接口暴露 Chrome DevTools 能力
- **前端排障**：让 coding agents 直接操作浏览器、捕获控制台 / 网络 / 性能数据
- **官方维护**：由 Chrome DevTools 团队维护
