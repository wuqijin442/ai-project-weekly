## 项目定位

面向 **AI 编码 Agent 的前端设计语言（design guidance）**。一句话：`npx impeccable install` 后在 AI 编码工具里跑 `/impeccable init`，即可让 Cursor / Claude Code / Windsurf 等生成的 UI 摆脱「千篇一律的 SaaS 模板味」。起点继承自 Anthropic 官方 `frontend-design` 技能，但扩展为「1 个 skill + 23 条命令 + 60 条确定性检测规则 + 实时浏览器迭代」的完整设计操作系统。

## 技术栈

- **形态**：AI 编码 Agent 设计技能（Skill）+ CLI + 浏览器扩展
- **核心能力**：
  - **一键初始化**：`/impeccable init` 生成 `PRODUCT.md` 与 `DESIGN.md`，固化受众 / 品牌 / 语调 / 反例 / 配色 / 字体 / 组件
  - **23 条命令**：与 AI 共享设计词汇——`polish`、`audit`、`critique`、`distill`、`animate`、`bolder`、`quieter` 等
  - **60 条确定性检测规则** + LLM  critiques：CLI 与浏览器扩展**零 LLM、零 API key** 即可跑确定性规则，识别 Inter 滥用、紫蓝渐变、卡片套卡片、灰字配彩底等「AI 设计 tell」
- **分发**：`npx impeccable install`；适配各类 AI 编码工具
