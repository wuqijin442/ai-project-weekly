## 项目定位

月之暗面（Moonshot AI）出品的**终端 AI 编码 Agent**。在命令行中读取/编辑代码、执行 shell 命令、搜索并抓取网页，并在执行过程中自主规划与调整动作，帮助完成软件开发与终端操作任务。

> 注：kimi-cli 正演进为 **Kimi Code CLI**（[MoonshotAI/kimi-code](https://github.com/MoonshotAI/kimi-code)），同团队下一代终端 AI Agent；安装 Kimi Code CLI 会自动迁移配置与会话，本项目将逐步收尾，文档与既有安装仍可用。

## 技术栈

- **语言/分发**：Python（PyPI 包 `kimi-cli`），跨平台
- **运行形态**：终端 Agent，可切换 shell 命令模式（Ctrl-X 直接在 Kimi CLI 内跑 shell 命令）
- **IDE 集成**：VS Code 扩展（Kimi Code Extension）；通过 **ACP（Agent Client Protocol）** 原生支持 IDE 集成
- **能力**：代码读写、shell 执行、网页搜索/抓取、自主规划
- **生态**：DeepWiki 文档，commit-activity / checks 徽章，社区 Discord
