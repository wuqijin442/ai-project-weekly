## 项目定位

GitHub 官方出品的 **Spec-Driven Development（规格驱动开发，SDD）** 上手工具包。帮助开发者/AI Agent 在动手写代码之前，先用结构化方式把需求写成规格（spec）与产品需求文档（PRD），再据此推进实现、测试与交付。

核心价值：把「先写 spec 再写代码」从理念变成可落地的脚手架。工具内置与 **GitHub Copilot** 深度对接的工作流，是当前大厂把 SDD 推向标准工程实践的最强信号之一。
