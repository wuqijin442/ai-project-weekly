## 项目定位

面向自主 AI Agent 的治理工具包——把「策略执行、零信任身份、执行沙箱、可靠性工程」打包，帮助团队把 Agent 安全地送上生产环境。官方宣称覆盖 **10/10 OWASP Agentic Top 10** 风险。

## 核心特性

- **策略引擎（Policy Engine）**：以策略约束 Agent 的行为边界。
- **零信任身份（Zero-Trust Identity）**：对 Agent 调用做身份与权限校验。
- **执行沙箱（Execution Sandboxing）**：隔离 Agent 的执行环境，降低破坏面。
- **可靠性工程**：面向生产运维的可观测与容错能力。
- **多语言分发**：PyPI（`agent-governance-toolkit`）、npm（`@microsoft/agent-governance-sdk`）、NuGet（`Microsoft.AgentGovernance`）三栖可用。
- **合规对齐**：标签含 compliance / owasp / ai-safety / trust，配套完整文档站点。

## 使用场景

- 把编码 Agent / 自主 Agent 接入企业时的合规与权限治理。
- 在 CI/CD 或生产环境对 Agent 动作做策略拦截与审计。
- 满足 OWASP Agentic Top 10 的安全基线。
