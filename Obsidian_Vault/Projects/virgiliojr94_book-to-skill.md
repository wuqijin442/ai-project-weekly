## 项目定位

把任何技术书、文档文件夹或多源资料，转换成统一的 Agent Skill——可在 GitHub Copilot CLI、Amp 或 Claude Code 中边工作边学习、引用、使用。让长文档「可检索、可对话、可复用」。

## 核心特性

- **多格式输入**：PDF · EPUB · DOCX · MD · HTML · RTF · MOBI 均支持。
- **符合 Agent Skills Open Standard**：产出遵循开放的 Agent Skills 规范，跨 Claude Code / Copilot CLI / Amp 等主机通用。
- **一键产出技能包**：自动抽取章节结构、关键概念、代码样例，生成可供 Agent 即时加载的 SKILL.md 与参考资料。
- **里程碑**：Trendshift 2026-05-23「当日 #10 Python 仓库 / #25 全站仓库」。

## 使用场景

- 把一本框架官方文档转成技能，边写代码边让 Agent 引用正确 API。
- 把内部知识库 / 规范文档转成团队共享 Skill。
- 把课程教材转成可对话的学习助手。
