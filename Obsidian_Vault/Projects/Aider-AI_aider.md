# Aider-AI/aider

> aider is AI pair programming in your terminal

## 项目定位

Aider 是一款在终端中运行的 AI 结对编程工具，最大特色是**深度 Git 集成**——每次 AI 修改代码后自动生成合理的 Git commit 信息。支持多文件协同编辑，可直接在命令行中与代码库对话。是目前 Vibe Coding 赛道最成熟的终端工具之一。
