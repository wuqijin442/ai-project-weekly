# 容器查询单位 cqw/cqh/cqi/cqb

## 问题/场景
响应式字号、间距通常用 `vw`/`vh`，但 `vw` 基于浏览器视口，组件被放在窄侧边栏或宽主区域时字号一样大，不符合直觉。我们希望组件内的字号、间距基于**容器尺寸**变化，而不是视口尺寸。

## 核心原理
容器查询单位基于最近的**容器查询上下文**（`container-type`）的尺寸：
- `cqw`：容器宽度的 1%
- `cqh`：容器高度的 1%
- `cqi`：容器内联尺寸的 1%（默认等于 cqw，书写方向相关）
- `cqb`：容器块尺寸的 1%（默认等于 cqh）
- `cqmin`：`min(cqi, cqb)`
- `cqmax`：`max(cqi, cqb)`

与 `vw`/`vh` 区别：`vw` 看整个浏览器窗口，`cqw` 看最近的容器。组件被放在侧边栏（窄）或主区域（宽）字号会自动适配。

## 实现方案

### 基础：容器响应式字号

```css
:root {
  --min-font: 0.875rem;
  --max-font: 1.5rem;
}

/* ① 声明容器查询上下文 */
.card-container {
  container-type: inline-size;
  container-name: card;
}

/* ② 用 cqi 让字号跟随容器宽度变化 */
.card {
  /* 字号在 0.875rem ~ 1.5rem 之间，随容器宽度变化 */
  font-size: clamp(var(--min-font), 5cqi, var(--max-font));
}

/* 内部所有尺寸都可以用容器单位 */
.card .title {
  font-size: clamp(1rem, 6cqi, 1.8rem);
  margin-bottom: 2cqi;
}

.card .content {
  font-size: clamp(0.875rem, 3.5cqi, 1rem);
  padding: 3cqi;
}
```

### 卡片栅格自适应

```css
/* 容器：栅格布局，列数随容器宽度变化 */
.grid {
  container-type: inline-size;
  display: grid;
  gap: 16px;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
}

/* 卡片内部用容器单位 */
.grid .card {
  /* 标题字号随容器变化，比 vw 更精确 */
  font-size: clamp(0.875rem, 4cqi, 1.25rem);
  padding: clamp(8px, 3cqi, 24px);
}

/* 配合容器查询切换布局 */
@container (min-width: 600px) {
  .card {
    display: grid;
    grid-template-columns: 1fr 2fr;
    gap: 16px;
  }
}
```

### 与 vw/vh 对比示例

```css
/* ❌ vw：基于视口，组件被放到窄侧栏字号也很大 */
.bad-card {
  font-size: 3vw;  /* 视口 1200px 时 36px，组件被挤到 300px 容器里还是 36px */
}

/* ✅ cqi：基于容器，组件放到任何地方都自适应 */
.good-card-container {
  container-type: inline-size;
}
.good-card {
  font-size: 5cqi;  /* 容器 300px 时 15px，容器 600px 时 30px，真正响应容器 */
}
```

### 全套单位使用

```css
.square-container {
  container-type: size;  /* 必须用 size 才能用 cqh/cqb */
  width: 400px;
  height: 300px;
}

.square-container .box {
  width: 50cqw;       /* 容器宽度的 50% = 200px */
  height: 50cqh;      /* 容器高度的 50% = 150px */
  font-size: 5cqmin;  /* min(cqi, cqb) 的 5% = 7.5px */
  padding: 4cqmax;    /* max(cqi, cqb) 的 4% = 16px */
}
```

## 执行步骤
1. **找父容器加 `container-type: inline-size`**：声明为容器上下文
2. **子元素用 `cqw`/`cqi` 代替 `vw`**：字号、间距、padding 都可用
3. **配合 `clamp()` 设上下限**：避免容器极端小时字号太小
4. **需要高度单位用 `container-type: size`**：但 size 模式要求容器有明确高度
5. **配合 `@container` 媒体查询切换布局**：实现真正的组件级响应式

## 兼容性
- Chrome: 105+
- Firefox: 110+

## 降级方案
```css
/* 老浏览器：用 vw 作为粗略降级 */
.card {
  font-size: clamp(0.875rem, 3vw, 1.25rem);
}

@supports (container-type: inline-size) {
  .card-container {
    container-type: inline-size;
  }
  .card {
    font-size: clamp(0.875rem, 5cqi, 1.25rem);
  }
}
```

## 单位对比
| 单位 | 基准 | 等价 | 适用 |
|------|------|------|------|
| `cqw` | 容器宽度 1% | 默认 = cqi | 横向布局 |
| `cqh` | 容器高度 1% | 默认 = cqb | 纵向布局 |
| `cqi` | 内联尺寸 1% | - | 通用（推荐） |
| `cqb` | 块尺寸 1% | - | 通用 |
| `cqmin` | min(cqi, cqb) | - | 安全保守 |
| `cqmax` | max(cqi, cqb) | - | 极限填充 |
| `vw` | 视口宽度 1% | - | 全局响应 |
| `vh` | 视口高度 1% | - | 全屏布局 |
