# 鼠标跟随效果

## 问题/场景
实现鼠标移动时元素跟随旋转（3D 卡片倾斜）、光晕跟随鼠标位置、磁吸效果。纯 CSS 无法监听鼠标坐标，需用最小 JS 把坐标写入 CSS 变量，CSS 负责所有视觉与动画。

## 核心原理
- CSS 自定义属性（变量）可以在 JS 中通过 `element.style.setProperty('--x', value)` 动态更新
- 在 `:root` 或元素上定义 `--x`、`--y`，CSS 用 `calc()` 与 `transform` 应用
- `pointermove` 事件统一处理鼠标与触摸（移动端）
- 关键：JS 只做坐标采集与变量更新，所有动画/过渡由 CSS `transition` 处理，性能更好
- 用 `transform: translate()` 而非 `top/left`，避免重排

## 实现方案
```css
:root {
  --mouse-x: 50%;
  --mouse-y: 50%;
  --glow-color: rgba(0, 229, 255, 0.4);
  --card-bg: #0f172a;
  --text-color: #f8fafc;
}

/* === 方案 1：光晕跟随鼠标 === */
.glow-card {
  position: relative;
  width: 320px;
  height: 200px;
  background: var(--card-bg);
  border-radius: 16px;
  overflow: hidden;
  cursor: pointer;
  color: var(--text-color);
  /* 关键：用 CSS 变量驱动 radial-gradient 中心 */
  --glow-x: var(--mouse-x);
  --glow-y: var(--mouse-y);
}

.glow-card::before {
  content: '';
  position: absolute;
  inset: 0;
  background: radial-gradient(
    circle 120px at var(--glow-x) var(--glow-y),
    var(--glow-color),
    transparent 70%
  );
  opacity: 0;
  transition: opacity 0.3s ease;
  pointer-events: none;
}

.glow-card:hover::before {
  opacity: 1;
}

/* === 方案 2：3D 卡片倾斜跟随 === */
.tilt-card {
  width: 240px;
  height: 320px;
  background: var(--card-bg);
  border-radius: 16px;
  transform-style: preserve-3d;
  transform:
    perspective(800px)
    rotateX(var(--rot-x, 0deg))
    rotateY(var(--rot-y, 0deg));
  transition: transform 0.1s ease;
  will-change: transform;
  color: var(--text-color);
}

/* 卡片内容用 translateZ 提升层次感 */
.tilt-card .content {
  transform: translateZ(40px);
  padding: 24px;
}

@media (prefers-color-scheme: dark) {
  :root { --card-bg: #ffffff; --text-color: #0f172a; }
}
```

配套最小 JS（仅采集坐标写入变量，不处理动画）：
```js
// 光晕跟随
const glowCards = document.querySelectorAll('.glow-card');
glowCards.forEach(card => {
  card.addEventListener('pointermove', e => {
    const rect = card.getBoundingClientRect();
    const x = ((e.clientX - rect.left) / rect.width) * 100;
    const y = ((e.clientY - rect.top) / rect.height) * 100;
    card.style.setProperty('--mouse-x', x + '%');
    card.style.setProperty('--mouse-y', y + '%');
  });
});

// 3D 倾斜跟随
const tiltCards = document.querySelectorAll('.tilt-card');
tiltCards.forEach(card => {
  card.addEventListener('pointermove', e => {
    const rect = card.getBoundingClientRect();
    // 鼠标相对中心的位置，转为 -10°~10° 旋转
    const cx = (e.clientX - rect.left - rect.width / 2) / (rect.width / 2);
    const cy = (e.clientY - rect.top - rect.height / 2) / (rect.height / 2);
    card.style.setProperty('--rot-y', (cx * 10) + 'deg');
    card.style.setProperty('--rot-x', (-cy * 10) + 'deg');
  });
  card.addEventListener('pointerleave', () => {
    card.style.setProperty('--rot-x', '0deg');
    card.style.setProperty('--rot-y', '0deg');
  });
});
```

## 执行步骤
1. 在元素上定义 CSS 变量 `--mouse-x`/`--mouse-y`（默认值 50%）
2. JS 用 `pointermove` 事件（统一鼠标/触摸）监听坐标
3. JS 计算 `e.clientX - rect.left` 得到相对坐标，转为百分比
4. JS 调用 `element.style.setProperty('--mouse-x', value)` 写入变量，**不操作 transform**
5. CSS 用 `radial-gradient(... at var(--mouse-x) var(--mouse-y))` 让光晕跟随
6. 3D 倾斜同理：JS 写 `--rot-x`/`--rot-y`，CSS `transform: rotateX(var(--rot-x))`
7. 动画与过渡全交给 CSS `transition`，JS 只更新变量

## 兼容性
- CSS 变量：Chrome 49+、Firefox 31+、Safari 9.1+
- `pointermove` 事件：全浏览器支持
- `transform-style: preserve-3d`：Chrome 36+、Firefox 16+、Safari 9+
- `will-change`：全浏览器支持

## 降级方案
```css
@supports not (--custom: property) {
  /* 不支持 CSS 变量时，关闭跟随效果，显示静态光晕 */
  .glow-card::before {
    background: radial-gradient(
      circle at 50% 50%,
      var(--glow-color),
      transparent 70%
    );
    opacity: 1;
  }
}

/* 用户偏好减少动画 */
@media (prefers-reduced-motion: reduce) {
  .tilt-card {
    transition: none;
    transform: none;
  }
}
```
