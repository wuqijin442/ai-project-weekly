# 拖拽交互

## 问题/场景
实现拖拽排序的视觉反馈、可拖动滑块的美化。HTML5 Drag API 提供原生拖拽能力，CSS 负责拖拽过程中的视觉反馈（拖动源半透明、放置区高亮）；`<input type="range">` 配合 `appearance: none` 可深度美化滑块。

## 核心原理
- HTML5 Drag API：元素 `draggable="true"`，监听 `dragstart`/`dragover`/`drop` 事件
- CSS 拖拽视觉状态：
  - `:drag` 伪类（实验性，Firefox 支持）
  - 用 JS 在 `dragstart`/`dragend` 切换 class
  - 拖动源默认半透明（浏览器行为）
- `input[type="range"]` 美化：
  - `appearance: none` 移除原生样式（需 `-webkit-` 与 `-moz-` 前缀）
  - 用 `::-webkit-slider-thumb` / `::-moz-range-thumb` 美化滑块
  - 用 `::-webkit-slider-runnable-track` 美化轨道
  - 用 `background: linear-gradient(...)` 配合 JS 计算 `--value` 实现填充进度

## 实现方案
```css
:root {
  --track-bg: #e2e8f0;
  --track-fill: #00e5ff;
  --thumb-bg: #ffffff;
  --thumb-border: #00e5ff;
  --drop-zone-bg: #f8fafc;
  --drop-zone-active: #e0f2fe;
  --text-color: #0f172a;
}

/* === 方案 1：拖拽列表视觉反馈 === */
.drag-list {
  list-style: none;
  padding: 0;
  margin: 0;
}
.drag-item {
  padding: 16px;
  background: var(--drop-zone-bg);
  border: 1px solid var(--track-bg);
  border-radius: 8px;
  margin-bottom: 8px;
  cursor: grab;
  transition: transform 0.2s ease, opacity 0.2s ease, box-shadow 0.2s ease;
  user-select: none;
  color: var(--text-color);
}
.drag-item:active {
  cursor: grabbing;
}
/* 拖动中的元素（JS 在 dragstart 加 .is-dragging） */
.drag-item.is-dragging {
  opacity: 0.5;
  transform: scale(0.98);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
}
/* 放置目标高亮（JS 在 dragover 加 .is-drop-target） */
.drop-zone {
  padding: 24px;
  border: 2px dashed var(--track-bg);
  border-radius: 12px;
  transition: border-color 0.2s ease, background 0.2s ease;
  min-height: 80px;
}
.drop-zone.is-drop-target {
  border-color: var(--track-fill);
  background: var(--drop-zone-active);
}

/* === 方案 2：input range 滑块美化 === */
.slider {
  -webkit-appearance: none;
  appearance: none;
  width: 100%;
  height: 8px;
  border-radius: 4px;
  /* 用渐变模拟填充：--value 由 JS 实时更新（0-100） */
  background: linear-gradient(
    to right,
    var(--track-fill) 0%,
    var(--track-fill) var(--value, 50%),
    var(--track-bg) var(--value, 50%),
    var(--track-bg) 100%
  );
  outline: none;
  cursor: pointer;
}

/* WebKit 滑块 */
.slider::-webkit-slider-thumb {
  -webkit-appearance: none;
  appearance: none;
  width: 24px;
  height: 24px;
  border-radius: 50%;
  background: var(--thumb-bg);
  border: 2px solid var(--thumb-border);
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.2);
  cursor: grab;
  transition: transform 0.2s ease;
  /* 触摸目标达标 24px+ */
}
.slider::-webkit-slider-thumb:hover {
  transform: scale(1.15);
}
.slider::-webkit-slider-thumb:active {
  cursor: grabbing;
  transform: scale(1.1);
}

/* Firefox 滑块 */
.slider::-moz-range-thumb {
  width: 24px;
  height: 24px;
  border-radius: 50%;
  background: var(--thumb-bg);
  border: 2px solid var(--thumb-border);
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.2);
  cursor: grab;
  transition: transform 0.2s ease;
}
.slider::-moz-range-thumb:hover {
  transform: scale(1.15);
}

/* Firefox 轨道单独美化 */
.slider::-moz-range-track {
  height: 8px;
  border-radius: 4px;
  background: var(--track-bg);
}

@media (prefers-color-scheme: dark) {
  :root {
    --track-bg: #334155;
    --thumb-bg: #1e293b;
    --drop-zone-bg: #1e293b;
    --text-color: #f8fafc;
  }
}
```

配套最小 JS（滑块进度填充）：
```js
// 滑块进度填充：监听 input 事件更新 --value 变量
const sliders = document.querySelectorAll('.slider');
sliders.forEach(slider => {
  const update = () => {
    const min = +slider.min || 0;
    const max = +slider.max || 100;
    const val = +slider.value;
    const percent = ((val - min) / (max - min)) * 100;
    slider.style.setProperty('--value', percent + '%');
  };
  slider.addEventListener('input', update);
  update(); // 初始化
});

// 拖拽列表：仅切换 class，视觉由 CSS 处理
const items = document.querySelectorAll('.drag-item');
items.forEach(item => {
  item.addEventListener('dragstart', () => item.classList.add('is-dragging'));
  item.addEventListener('dragend', () => item.classList.remove('is-dragging'));
});
const dropZones = document.querySelectorAll('.drop-zone');
dropZones.forEach(zone => {
  zone.addEventListener('dragover', e => {
    e.preventDefault();
    zone.classList.add('is-drop-target');
  });
  zone.addEventListener('dragleave', () => zone.classList.remove('is-drop-target'));
  zone.addEventListener('drop', () => zone.classList.remove('is-drop-target'));
});
```

## 执行步骤
1. **拖拽列表**：元素加 `draggable="true"`，JS 在 `dragstart`/`dragend` 切换 `.is-dragging` class
2. CSS 用 `.is-dragging` 控制半透明 + 缩放 + 阴影反馈
3. 放置区 `dragover` 事件需 `e.preventDefault()` 才能触发 `drop`
4. **滑块美化**：`appearance: none` 移除原生样式，统一用 CSS 重绘
5. 用 `linear-gradient` + `--value` 变量模拟填充进度，JS 在 `input` 事件更新变量
6. WebKit 与 Firefox 的伪元素不同，需分别写 `::-webkit-slider-thumb` 与 `::-moz-range-thumb`
7. 暗黑模式切换轨道与滑块变量

## 兼容性
- HTML5 Drag API：全浏览器支持（移动端有限）
- `appearance: none`：全浏览器支持（需前缀）
- `::-webkit-slider-thumb`：Chrome/Safari/Edge
- `::-moz-range-thumb`：Firefox
- `pointer-events` 触摸拖拽：移动端推荐用 Pointer Events 替代 Drag API

## 降级方案
```css
@supports not (appearance: none) {
  /* 不支持 appearance: none 时保留原生滑块 */
  .slider {
    appearance: auto;
    -webkit-appearance: auto;
  }
}

/* 触摸设备：Drag API 支持有限，降级为提示 */
@media (hover: none) and (pointer: coarse) {
  .drag-item {
    cursor: default;
  }
  .drag-item::after {
    content: '（长按拖动）';
    font-size: 12px;
    color: var(--text-color);
    opacity: 0.6;
    margin-left: 8px;
  }
}
```
