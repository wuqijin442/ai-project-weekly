# 3D翻转卡片

## 问题/场景
点击或 hover 时卡片翻转，露出背面内容（如会员卡正反面、产品详情切换）。需要纯 CSS 实现，且支持点击触发（而非仅 hover，移动端友好）。

## 核心原理
- 父容器 `perspective` 建立景深（参考 [[perspective-透视]]）
- 卡片 `transform-style: preserve-3d` + `transform: rotateY(180deg)` 翻转
- 正反两面 `position: absolute` 叠在一起，都设 `backface-visibility: hidden`
- 背面预先 `rotateY(180deg)`，翻转后背面"正过来"显示
- 点击翻转：用 `<input type="checkbox">` + `<label>` + `:checked` 选择器，无需 JS

## 实现方案
```css
:root {
  --front-color: #00e5ff;
  --back-color: #a78bfa;
  --text-color: #0f172a;
  --bg-color: #ffffff;
}

/* 父容器提供景深 */
.flip-scene {
  perspective: 1000px;
  width: 240px;
  height: 320px;
}

/* 用 checkbox + label 实现点击翻转 */
.flip-scene input {
  position: absolute;
  opacity: 0;
  pointer-events: none;
}

.flip-card {
  position: relative;
  width: 100%;
  height: 100%;
  transform-style: preserve-3d;
  transition: transform 0.6s cubic-bezier(0.4, 0, 0.2, 1);
  cursor: pointer;
}

/* :checked 触发翻转 */
.flip-scene input:checked + .flip-card {
  transform: rotateY(180deg);
}

/* hover 也能翻转（可选） */
.flip-card:hover {
  transform: rotateY(180deg);
}

.flip-card .face {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
  -webkit-backface-visibility: hidden;
  display: grid;
  place-items: center;
  border-radius: 16px;
  padding: 24px;
  text-align: center;
  color: var(--text-color);
}

.flip-card .front {
  background: var(--front-color);
}

.flip-card .back {
  background: var(--back-color);
  transform: rotateY(180deg); /* 背面预先翻转 */
}

@media (prefers-color-scheme: dark) {
  :root { --text-color: #f8fafc; --bg-color: #0f172a; }
}
```

HTML 结构：
```html
<div class="flip-scene">
  <input type="checkbox" id="flip1">
  <label for="flip1" class="flip-card">
    <div class="face front">正面内容</div>
    <div class="face back">背面内容</div>
  </label>
</div>
```

## 执行步骤
1. 父容器 `.flip-scene` 加 `perspective: 1000px` 建立景深
2. 卡片 `.flip-card` 加 `transform-style: preserve-3d`，`transition` 让翻转有动画
3. 正反两面 `.face` 用 `position: absolute; inset: 0` 完全重叠
4. 两面都加 `backface-visibility: hidden`，背面预先 `rotateY(180deg)`
5. 点击翻转：用 `<input type="checkbox">` 隐藏，`<label>` 包裹卡片，`:checked + .flip-card` 触发 `rotateY(180deg)`
6. 暗黑模式只切换变量

## 兼容性
- Chrome: 36+
- Firefox: 16+
- Safari: 9+（部分老版本需 `-webkit-` 前缀）
- 移动端全面支持

## 降级方案
```css
@supports not (transform-style: preserve-3d) {
  /* 不支持 3D 时降级为透明度切换 */
  .flip-card .face {
    backface-visibility: visible;
    transition: opacity 0.3s ease;
  }
  .flip-card .back {
    opacity: 0;
    transform: none;
  }
  .flip-scene input:checked + .flip-card .back {
    opacity: 1;
  }
  .flip-scene input:checked + .flip-card .front {
    opacity: 0;
  }
}
```
