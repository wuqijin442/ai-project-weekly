# 磨砂玻璃3D

## 问题/场景
在 3D 场景中叠加磨砂玻璃质感（毛玻璃），常用于 3D 卡片悬浮、景深虚化背景、未来感 UI。难点是 `backdrop-filter` 在 3D 旋转下需要正确层级与 `translateZ` 配合。

## 核心原理
- `backdrop-filter: blur(10px)`：对元素**背后**的内容做模糊，营造毛玻璃
- 在 3D 场景中，用 `translateZ` 把玻璃层提到背景层前面，但仍在卡片前面
- 景深虚化：远处的元素（`translateZ` 负值大）配合 `filter: blur` 模拟相机景深
- 注意：`backdrop-filter` 与 `overflow: hidden` 同框可能让 `preserve-3d` 失效，需谨慎
- 性能：`backdrop-filter` 较重，长列表慎用，配合 `will-change` 提示浏览器

## 实现方案
```css
:root {
  --glass-bg: rgba(255, 255, 255, 0.15);
  --glass-border: rgba(255, 255, 255, 0.3);
  --text-color: #0f172a;
  --bg-gradient: linear-gradient(135deg, #667eea, #764ba2);
  --blur-amount: 12px;
}

.scene {
  perspective: 1000px;
  height: 400px;
  background: var(--bg-gradient);
  display: flex;
  justify-content: center;
  align-items: center;
  position: relative;
  overflow: hidden;
}

/* 3D 卡片容器 */
.glass-card-3d {
  position: relative;
  width: 260px;
  height: 320px;
  transform-style: preserve-3d;
  transform: rotateY(-15deg) rotateX(8deg);
  transition: transform 0.5s cubic-bezier(0.4, 0, 0.2, 1);
  will-change: transform;
}

.glass-card-3d:hover {
  transform: rotateY(0deg) rotateX(0deg) translateZ(20px);
}

/* 磨砂玻璃面：backdrop-filter 模糊背后内容 */
.glass-face {
  position: absolute;
  inset: 0;
  background: var(--glass-bg);
  backdrop-filter: blur(var(--blur-amount)) saturate(180%);
  -webkit-backdrop-filter: blur(var(--blur-amount)) saturate(180%);
  border: 1px solid var(--glass-border);
  border-radius: 20px;
  transform: translateZ(40px); /* 玻璃面提到前面 */
  box-shadow:
    0 8px 32px rgba(0, 0, 0, 0.2),
    inset 0 1px 0 rgba(255, 255, 255, 0.4);
  padding: 24px;
  color: var(--text-color);
}

/* 景深虚化：背景层用 filter: blur 模拟相机失焦 */
.depth-bg {
  position: absolute;
  inset: -50px;
  background: var(--bg-gradient);
  transform: translateZ(-100px);
  filter: blur(20px); /* 远处虚化 */
  opacity: 0.6;
}

/* 高光反射条 */
.glass-face::before {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  height: 50%;
  background: linear-gradient(
    180deg,
    rgba(255, 255, 255, 0.2),
    transparent
  );
  border-radius: 20px 20px 0 0;
  pointer-events: none;
}

@media (prefers-color-scheme: dark) {
  :root {
    --glass-bg: rgba(15, 23, 42, 0.4);
    --text-color: #f8fafc;
  }
}
```

## 执行步骤
1. 父容器 `.scene` 加 `perspective: 1000px` 与渐变背景
2. 卡片 `.glass-card-3d` 加 `transform-style: preserve-3d`，整体 `rotateY/X` 倾斜
3. 磨砂玻璃面 `backdrop-filter: blur(12px)` 模糊背后内容，`background: rgba` 半透明
4. 用 `translateZ(40px)` 把玻璃面提到前景，制造立体浮起感
5. 景深虚化：背景层 `translateZ(-100px)` 推远 + `filter: blur(20px)` 模拟相机失焦
6. 暗黑模式提高玻璃透明度对比，确保文字可读

## 兼容性
- Chrome: 76+（`backdrop-filter` 标准支持）
- Firefox: 103+（默认启用，之前需 about:config）
- Safari: 9+（需 `-webkit-` 前缀，最早支持）
- 注意：`backdrop-filter` 与 `overflow: hidden` 组合可能破坏 `preserve-3d`

## 降级方案
```css
@supports not (backdrop-filter: blur(10px)) {
  .glass-face {
    /* 不支持 backdrop-filter 时降级为半透明背景 */
    background: rgba(255, 255, 255, 0.6);
    backdrop-filter: none;
  }
}

@supports not (transform-style: preserve-3d) {
  .glass-card-3d {
    /* 不支持 3D 时去掉旋转 */
    transform: none;
  }
}
```
