# 3D立方体

## 问题/场景
用 6 个 div 拼出一个可旋转的 3D 立方体，常用于产品展示、3D 相册、加载动画。难点在于 6 个面如何用 `rotateX/Y + translateZ` 拼接到正确位置。

## 核心原理
- 父容器 `perspective` 提供景深
- 立方体容器 `transform-style: preserve-3d` 让 6 个面共享 3D 空间
- 6 个面定位公式（假设立方体边长为 L，半边长 H = L/2）：
  - 前：`translateZ(H)`
  - 后：`rotateY(180deg) translateZ(H)`
  - 右：`rotateY(90deg) translateZ(H)`
  - 左：`rotateY(-90deg) translateZ(H)`
  - 上：`rotateX(90deg) translateZ(H)`
  - 下：`rotateX(-90deg) translateZ(H)`
- 关键顺序：先旋转再平移（`rotateY(90deg) translateZ(H)`），让平移方向沿旋转后的局部坐标系

## 实现方案
```css
:root {
  --cube-size: 200px;
  --face-color-1: rgba(0, 229, 255, 0.7);
  --face-color-2: rgba(100, 200, 255, 0.7);
  --face-color-3: rgba(167, 139, 250, 0.7);
  --bg-color: #0f172a;
}

.scene {
  perspective: 1200px;
  width: var(--cube-size);
  height: var(--cube-size);
  margin: 100px auto;
}

.cube {
  position: relative;
  width: 100%;
  height: 100%;
  transform-style: preserve-3d;
  animation: rotate3d 12s linear infinite;
}

@keyframes rotate3d {
  from { transform: rotateX(0) rotateY(0); }
  to   { transform: rotateX(360deg) rotateY(360deg); }
}

/* 6 个面通用样式 */
.face {
  position: absolute;
  inset: 0;
  display: grid;
  place-items: center;
  font-size: 32px;
  font-weight: 900;
  color: #fff;
  border: 2px solid rgba(255, 255, 255, 0.3);
  background: var(--face-color-1);
}

/* 半边长 = var(--cube-size) / 2 */
.face.front  { transform: translateZ(calc(var(--cube-size) / 2)); background: var(--face-color-1); }
.face.back   { transform: rotateY(180deg) translateZ(calc(var(--cube-size) / 2)); background: var(--face-color-2); }
.face.right  { transform: rotateY(90deg) translateZ(calc(var(--cube-size) / 2)); background: var(--face-color-3); }
.face.left   { transform: rotateY(-90deg) translateZ(calc(var(--cube-size) / 2)); background: var(--face-color-1); }
.face.top    { transform: rotateX(90deg) translateZ(calc(var(--cube-size) / 2)); background: var(--face-color-2); }
.face.bottom { transform: rotateX(-90deg) translateZ(calc(var(--cube-size) / 2)); background: var(--face-color-3); }

@media (prefers-color-scheme: dark) {
  :root { --bg-color: #f8fafc; }
}
```

HTML 结构：
```html
<div class="scene">
  <div class="cube">
    <div class="face front">前</div>
    <div class="face back">后</div>
    <div class="face right">右</div>
    <div class="face left">左</div>
    <div class="face top">上</div>
    <div class="face bottom">下</div>
  </div>
</div>
```

## 执行步骤
1. 父容器 `.scene` 加 `perspective: 1200px`，尺寸等于立方体边长
2. `.cube` 加 `transform-style: preserve-3d`，让 6 个面共享 3D 空间
3. 6 个面 `position: absolute; inset: 0` 完全重叠在原点
4. **关键**：每个面先旋转（确定朝向）再 `translateZ(半边长)`（推到对应位置），顺序不能反
5. `@keyframes` 同时 `rotateX` 和 `rotateY` 0→360deg 实现自动旋转
6. 调整 `--cube-size` 变量即可改变立方体大小，所有面自动适配

## 兼容性
- Chrome: 36+
- Firefox: 16+
- Safari: 9+
- 移动端全面支持

## 降级方案
```css
@supports not (transform-style: preserve-3d) {
  .cube {
    /* 不支持 3D 时降级为 2D 网格展示 */
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    animation: none;
  }
  .face {
    position: static;
    transform: none;
    inset: auto;
  }
}
```
