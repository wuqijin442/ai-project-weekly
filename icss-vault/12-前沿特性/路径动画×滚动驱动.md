# 路径动画 × 滚动驱动

## 问题/场景
滚动页面时，希望某个元素沿 SVG 路径移动（如曲线进度条、视差小球、沿曲线飘落的元素）。传统做法要 JS 监听 scroll 事件 + 计算路径坐标，性能差且代码复杂。我们希望纯 CSS 实现「滚动进度驱动元素沿路径移动」。

## 核心原理
三个核心属性配合：

1. **`offset-path: path('M0,0 C...')`**：定义元素运动的 SVG 路径
2. **`offset-distance: 0% → 100%`**：元素在路径上的位置（0% 起点 → 100% 终点）
3. **`offset-rotate: auto`**：元素自动跟随路径切线方向旋转

驱动方式有两种：
- **时间驱动**：传统 `animation` + `@keyframes`，时间推进
- **滚动驱动**：`animation-timeline: scroll()`，滚动进度驱动动画进度

`animation-timeline: scroll()` 是关键：滚动条位置直接映射为动画进度，无需 JS。

## 实现方案

### 基础：滚动驱动沿路径移动

```css
:root {
  --path-color: #007bff;
  --ball-size: 24px;
}

/* 容器：声明为滚动时间线源 */
.scroll-container {
  scroll-timeline: --scroll-progress block;  /* 块方向滚动作为时间线 */
  height: 300vh;  /* 长滚动区域 */
}

/* 沿路径移动的元素 */
.path-element {
  offset-path: path('M0,0 C100,100 200,0 300,100');  /* SVG 贝塞尔曲线 */
  offset-distance: 0%;
  offset-rotate: auto;  /* 自动跟随路径切线 */

  width: var(--ball-size);
  height: var(--ball-size);
  background: var(--path-color);
  border-radius: 50%;

  animation: moveAlongPath linear;
  animation-timeline: --scroll-progress;  /* 用滚动进度驱动 */
}

@keyframes moveAlongPath {
  to { offset-distance: 100%; }
}
```

### 配合 view() 时间线（元素进入视口触发）

```css
/* 元素进入视口时沿路径移动 */
.scroll-reveal {
  offset-path: path('M-100,0 L0,0 L100,0');
  offset-distance: 0%;

  animation: path-reveal linear;
  animation-timeline: view();  /* 元素进入视口驱动 */
  animation-range: entry 0% cover 30%;  /* 进入视口到覆盖 30% 时动画
}

@keyframes path-reveal {
  to { offset-distance: 100%; }
}
```

### 进度条沿路径填充

```css
.progress-path {
  offset-path: path('M10,80 C40,10 65,10 95,80 S150,150 180,80');
  offset-distance: 0%;

  /* 用 stroke-dasharray 模拟路径填充 */
  stroke: var(--path-color);
  stroke-width: 4;
  fill: none;
  stroke-dasharray: 1000;
  stroke-dashoffset: 1000;

  animation: fillPath linear;
  animation-timeline: scroll();  /* 根页面滚动驱动 */
}

@keyframes fillPath {
  to {
    stroke-dashoffset: 0;
    offset-distance: 100%;
  }
}
```

### 多元素错开路径动画

```css
.floating-leaf {
  offset-path: path('M0,0 Q50,-100 100,0 T200,0');
  offset-rotate: auto;

  animation: float-down 4s linear infinite;
}

/* 多个叶子错开时间和位置 */
.floating-leaf:nth-child(1) { animation-delay: 0s;   offset-distance: 0%; }
.floating-leaf:nth-child(2) { animation-delay: -1s;  offset-distance: 25%; }
.floating-leaf:nth-child(3) { animation-delay: -2s;  offset-distance: 50%; }
.floating-leaf:nth-child(4) { animation-delay: -3s;  offset-distance: 75%; }

@keyframes float-down {
  to { offset-distance: 100%; }
}
```

### 时间线类型对比

```css
/* 1. scroll()：基于文档滚动 */
.scroll-driven {
  animation-timeline: scroll(root);  /* 根文档滚动 */
}

/* 2. 自命名时间线：基于特定容器 */
.container {
  scroll-timeline: --my-timeline block;
}
.container .element {
  animation-timeline: --my-timeline;
}

/* 3. view()：基于元素进入视口 */
.view-driven {
  animation-timeline: view();
  animation-range: entry 0% exit 100%;  /* 从进入到离开视口
}
```

## 执行步骤
1. **设计 SVG 路径**：用 `M`（移动到）、`L`（直线）、`C`（贝塞尔）等命令
2. **元素加 `offset-path: path('...')`**：声明运动路径
3. **设置 `offset-distance: 0%`**：初始位置
4. **加 `offset-rotate: auto`**：元素跟随路径方向（可选 `0deg` 保持原方向）
5. **写 `@keyframes` 让 `offset-distance` 从 0% → 100%**
6. **绑定 `animation-timeline: scroll()` 或 `view()`**：用滚动驱动动画
7. **加 `@supports` 降级**：Firefox/Safari 部分不支持

## 兼容性
- `offset-path`: Chrome 79+/Firefox 72+/Safari 15.4+ ✅
- `animation-timeline: scroll()`: Chrome 115+/Firefox 实验性/Safari 不支持 ⚠️
- `animation-timeline: view()`: Chrome 115+/Firefox 实验性/Safari 不支持 ⚠️

## 降级方案
```css
/* 1. 时间驱动降级（去掉 animation-timeline，用时间驱动） */
@supports not (animation-timeline: scroll()) {
  .path-element {
    animation: moveAlongPath 4s linear infinite;  /* 时间驱动循环 */
  }
}

/* 2. JS 降级：监听 scroll 计算 offset-distance */
@supports not (animation-timeline: scroll()) {
  .path-element {
    offset-distance: 0%;  /* 由 JS 更新 */
  }
  /* JS:
  window.addEventListener('scroll', () => {
    const progress = window.scrollY / (document.body.scrollHeight - window.innerHeight);
    document.querySelector('.path-element').style.offsetDistance = (progress * 100) + '%';
  });
  */
}

/* 3. 完全降级：直线移动 */
@supports not (offset-path: path('M0,0')) {
  .path-element {
    /* 简化为水平移动 */
    animation: simple-move 4s linear infinite;
  }
  @keyframes simple-move {
    from { transform: translateX(0); }
    to   { transform: translateX(300px); }
  }
}
```

## offset-rotate 取值
| 取值 | 含义 | 适用 |
|------|------|------|
| `auto` | 跟随路径切线 | 小车、箭头沿路径 |
| `auto 90deg` | 切线 + 额外 90° | 修正朝向 |
| `0deg` | 保持原方向 | 圆点、文字 |
| `reverse` | 反向跟随 | 倒退效果 |

## 应用场景
| 场景 | 路径类型 | 驱动方式 |
|------|----------|----------|
| 滚动进度球 | 曲线 | `scroll()` |
| 视差飘叶 | 自由曲线 | 时间驱动 |
| 进入视口动画 | 短路径 | `view()` |
| 进度条填充 | 完整路径 | `scroll()` |
| 路线图绘制 | SVG 路径 | `scroll()` |
