# 渐变文字

## 问题/场景
让文字颜色呈现渐变效果，甚至流动起来。常见于标题、Logo、Hero 区域。普通 `color` 只能单色，渐变文字需要把背景渐变"裁切"到文字形状内。

## 核心原理
- `background-clip: text`：把背景裁切到文字字形区域（原值 `border-box`/`padding-box` 等）
- `-webkit-text-fill-color: transparent`：把文字默认填充色设为透明，露出底层背景
- 配合 `background-size: 200%` + 动画 `background-position` 即可流动
- 关键：`color` 会被 `text-fill-color` 覆盖，所以必须设 `text-fill-color: transparent`

## 实现方案
```css
:root {
  --grad-start: #00e5ff;
  --grad-mid: #64c8ff;
  --grad-end: #00e5ff;
  --bg-color: #0f172a;
}

.gradient-text {
  /* 1. 设置渐变背景 */
  background: linear-gradient(
    90deg,
    var(--grad-start),
    var(--grad-mid),
    var(--grad-end)
  );
  background-size: 200% 100%; /* 放大背景以供流动 */

  /* 2. 裁切到文字 */
  -webkit-background-clip: text;
  background-clip: text;

  /* 3. 文字填充透明，露出背景 */
  -webkit-text-fill-color: transparent;
  color: transparent; /* Firefox 兜底 */

  /* 4. 流动动画：只动 background-position，不触发重排 */
  animation: gradientShift 3s ease infinite;

  font-size: 48px;
  font-weight: 900;
}

@keyframes gradientShift {
  0%   { background-position: 0% 50%; }
  50%  { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

/* 暗黑主题：仅切换变量即可 */
@media (prefers-color-scheme: dark) {
  :root {
    --grad-start: #60a5fa;
    --grad-mid: #a78bfa;
    --grad-end: #60a5fa;
  }
}
```

## 执行步骤
1. 给元素一个 `linear-gradient` 渐变背景（先有背景，再裁切）
2. 加 `-webkit-background-clip: text` 与 `background-clip: text`，把背景裁到字形里
3. 设 `-webkit-text-fill-color: transparent` 让文字本身透明，渐变才显出来
4. 放大 `background-size: 200%`，再用 `@keyframes` 动 `background-position` 实现流动
5. 暗黑模式只改 CSS 变量，不动结构

## 兼容性
- Chrome: 4+（需 `-webkit-` 前缀），88+ 支持标准 `background-clip: text`
- Firefox: 49+ 支持
- Safari: 4+（需 `-webkit-` 前缀）

## 降级方案
```css
@supports not ((background-clip: text) or (-webkit-background-clip: text)) {
  .gradient-text {
    /* 降级为纯色 */
    color: var(--grad-start);
    background: none;
    -webkit-text-fill-color: currentcolor;
  }
}
```
