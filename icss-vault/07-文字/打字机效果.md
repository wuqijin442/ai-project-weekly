# 打字机效果

## 问题/场景
模拟打字机逐字显示文字，并带闪烁光标。常用于 Hero 副标题、终端风界面、代码演示。需要纯 CSS 实现且性能良好。

## 核心原理
- `steps(n)`：把动画分成 n 步跳跃执行（而非 linear 平滑过渡），实现"逐字"效果
- `ch` 单位：1ch 等于当前字体一个字符宽度（数字 0 的宽度），用它度量文字宽度精准
- 文字宽度从 0 到 N ch 用 `steps(N)` 切分，正好一次露一个字
- 配合 `white-space: nowrap; overflow: hidden` 裁切超出部分
- 光标用 `border-right` + `steps()` 闪烁，或 `::after` 伪元素

## 实现方案
```css
:root {
  --text-color: #0f172a;
  --cursor-color: #00e5ff;
  --bg-color: #ffffff;
}

.typewriter {
  font-family: 'Courier New', monospace;
  font-size: 24px;
  white-space: nowrap;
  overflow: hidden;

  /* 文字宽度 = 字符数 × 1ch，这里 11 个字符 */
  width: 11ch;

  /* steps(11) 把宽度增长分 11 步，每步露 1 个字 */
  animation: typing 2s steps(11) infinite alternate,
             blink 0.7s steps(1) infinite;

  border-right: 2px solid var(--cursor-color);
  color: var(--text-color);
}

@keyframes typing {
  from { width: 0; }
  to   { width: 11ch; }
}

/* 光标闪烁：只切 border-color，不动 transform/opacity 也行 */
@keyframes blink {
  50% { border-color: transparent; }
}

/* 多行打字：每行独立动画延迟 */
.multi-line {
  font-family: monospace;
  font-size: 18px;
  line-height: 1.6;
}
.multi-line .line {
  display: block;
  overflow: hidden;
  white-space: nowrap;
  width: 0;
  animation: lineType 2s steps(20) forwards;
}
.multi-line .line:nth-child(2) { animation-delay: 2s; }
.multi-line .line:nth-child(3) { animation-delay: 4s; }

@keyframes lineType {
  to { width: 20ch; }
}

@media (prefers-color-scheme: dark) {
  :root {
    --text-color: #f8fafc;
    --cursor-color: #60a5fa;
  }
}
```

## 执行步骤
1. 容器加 `white-space: nowrap; overflow: hidden`，让文字不换行且超出部分隐藏
2. 用 `width` 配合 `ch` 单位定义目标宽度（几个字符就写几 ch）
3. `@keyframes` 从 `width: 0` 到 `width: Nch`，配 `steps(N)` 逐字显示
4. 光标用 `border-right` 加 `steps(1)` 的 `blink` 动画切换颜色
5. 多行打字：每行独立动画 + `animation-delay` 错开时间

## 兼容性
- Chrome: 全版本支持 `steps()` 与 `ch`
- Firefox: 全版本支持
- Safari: 全版本支持
- 注意：`width` 动画会触发重排，长文本不建议用，可改用 `clip-path` 或 `transform`

## 降级方案
```css
@supports not (width: 1ch) {
  .typewriter {
    /* ch 不支持时改用 em 兜底 */
    width: 11em;
    animation: typing 2s steps(11) infinite alternate;
  }
  @keyframes typing {
    from { width: 0; }
    to   { width: 11em; }
  }
}

/* 用户偏好减少动画 */
@media (prefers-reduced-motion: reduce) {
  .typewriter {
    animation: none;
    width: auto;
  }
}
```
