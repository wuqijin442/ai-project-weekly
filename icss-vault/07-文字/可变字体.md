# 可变字体

## 问题/场景
一个字体文件包含所有字重（100-900）、字宽、斜度等变化，无需加载多个静态字体文件。可在 hover、滚动时平滑过渡字重，提升性能与动效质感。

## 核心原理
- **可变字体**：OpenType 字体规范扩展，单文件包含一个或多个"轴"（axis）
- **轴（axis）**：每个轴用 4 字母标签表示
  - `wght`：字重（100-900）
  - `wdth`：字宽（75-125，百分比）
  - `slnt`：倾斜（-90 到 90 度）
  - `ital`：斜体（0 或 1）
- `font-variation-settings: 'wght' 400, 'wdth' 100`：通过轴标签设置具体值
- `@font-face` 中 `src: url(...) format('woff2-variations')` 声明可变字体格式
- 配合 `transition: font-variation-settings 0.3s` 可实现字重平滑过渡

## 实现方案
```css
:root {
  --font-wght: 400;
  --font-wdth: 100;
}

/* 1. 引入可变字体 */
@font-face {
  font-family: 'Inter Variable';
  src: url('Inter-Variable.woff2') format('woff2-variations'),
       url('Inter-Variable.woff2') format('woff2');
  font-weight: 100 900; /* 声明字重范围，关键！ */
  font-display: swap;
}

/* 2. 基础样式 */
.variable-text {
  font-family: 'Inter Variable', system-ui, sans-serif;
  font-variation-settings: 'wght' var(--font-wght), 'wdth' var(--font-wdth);
  transition: font-variation-settings 0.3s cubic-bezier(0.4, 0, 0.2, 1);
  font-size: 32px;
}

/* 3. Hover 时字重过渡到 800 */
.variable-text:hover {
  --font-wght: 800;
}

/* 4. 滚动驱动字重变化（Chrome 115+） */
.scroll-weight {
  font-family: 'Inter Variable', sans-serif;
  font-variation-settings: 'wght' 400;
  animation: weightShift linear;
  animation-timeline: scroll();
  animation-range: cover 0% cover 100%;
}

@keyframes weightShift {
  to { font-variation-settings: 'wght' 900; }
}
```

## 执行步骤
1. 用 `@font-face` 引入可变字体文件，`format('woff2-variations')` 声明类型
2. `font-weight: 100 900` 声明字重范围（注意是范围不是单值），让浏览器知道这是可变字体
3. 用 `font-variation-settings: 'wght' 值` 替代 `font-weight` 控制字重
4. 加 `transition: font-variation-settings 0.3s`，hover 时改变量即可平滑过渡
5. `font-display: swap` 避免字体加载时白屏

## 兼容性
- Chrome: 60+ 支持 `font-variation-settings`
- Firefox: 62+
- Safari: 11.1+
- `animation-timeline: scroll()`：Chrome 115+，其他浏览器实验性

## 降级方案
```css
@supports not (font-variation-settings: 'wght' 400) {
  /* 不支持可变字体时降级为静态字重 */
  .variable-text {
    font-family: 'Inter', system-ui, sans-serif;
    font-weight: 400;
    transition: font-weight 0.3s ease;
  }
  .variable-text:hover {
    font-weight: 800;
  }
}
```
