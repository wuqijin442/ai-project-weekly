# 文字溢出省略

## 问题/场景
文字过长时用省略号 `…` 截断，单行/多行两种场景。Flex 布局下经常遇到"省略号不显示"的坑，根因是 Flex item 默认 `min-width: auto`。

## 核心原理
- **单行省略三件套**：`white-space: nowrap`（不换行）+ `overflow: hidden`（隐藏超出）+ `text-overflow: ellipsis`（显示省略号）
- **多行省略**：`display: -webkit-box` + `-webkit-box-orient: vertical` + `-webkit-line-clamp: N`
- **Flex 坑**：Flex item 的 `min-width` 默认是 `auto`（即内容宽度），会让子项撑爆容器，必须设 `min-width: 0` 才能让 `overflow: hidden` 生效

## 实现方案
```css
:root {
  --text-color: #0f172a;
  --bg-color: #ffffff;
}

/* 1. 单行省略 */
.ellipsis-single {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  color: var(--text-color);
}

/* 2. 多行省略（标准属性 line-clamp 已被现代浏览器支持） */
.ellipsis-multi {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3; /* 旧前缀 */
  line-clamp: 3;          /* 标准属性 */
  overflow: hidden;
  color: var(--text-color);
}

/* 3. Flex 布局中的省略：必须 min-width: 0 */
.flex-ellipsis {
  display: flex;
  gap: 12px;
  align-items: center;
}
.flex-ellipsis .text {
  min-width: 0; /* 关键：覆盖默认 auto，允许收缩 */
  flex: 1;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* 4. Grid 中同理 */
.grid-ellipsis {
  display: grid;
  grid-template-columns: auto 1fr;
  gap: 12px;
}
.grid-ellipsis .text {
  min-width: 0; /* Grid item 同样需要 */
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

@media (prefers-color-scheme: dark) {
  :root { --text-color: #f8fafc; }
}
```

## 执行步骤
1. **单行**：先 `white-space: nowrap` 强制不换行，再加 `overflow: hidden` 隐藏超出，最后 `text-overflow: ellipsis` 显示省略号
2. **多行**：用 `-webkit-box` 弹性盒模型 + 垂直方向 + `-webkit-line-clamp: N` 限定行数
3. **Flex 子项省略不生效**：根因是 `min-width: auto` 让子项不收缩，加 `min-width: 0` 即可解决
4. **Grid 子项**同理需要 `min-width: 0`
5. 暗黑模式只切换文字颜色变量

## 兼容性
- 单行三件套：全浏览器支持
- `-webkit-line-clamp`：Chrome 4+、Safari 4+、Firefox 68+
- 标准 `line-clamp`：Chrome 117+、Firefox 130+、Safari 17.4+
- `min-width: 0` 解决 Flex 省略失效：全浏览器支持

## 降级方案
```css
@supports not (-webkit-line-clamp: 2) {
  .ellipsis-multi {
    /* 降级方案：用 max-height + 行高计算 */
    display: block;
    max-height: 4.5em; /* 3 行 × 1.5em 行高 */
    line-height: 1.5em;
    overflow: hidden;
    position: relative;
  }
  /* 用伪元素叠加省略号 */
  .ellipsis-multi::after {
    content: '…';
    position: absolute;
    right: 0;
    bottom: 0;
    padding-left: 4px;
    background: var(--bg-color);
  }
}
```
