# 文字描边

## 问题/场景
给文字加描边（轮廓线）。常见需求：标题描边、镂空文字、加粗后再描边防止字重变细。`text-stroke` 会让字变细，需要 `paint-order` 调整顺序。

## 核心原理
- `-webkit-text-stroke: <width> <color>`：定义描边宽度和颜色
- 默认绘制顺序是 `fill stroke markers`，描边会盖住填充，导致字看起来变细
- `paint-order: stroke fill`：先描边后填充，让填充覆盖描边内侧，保持字重
- `text-shadow` 多重投影可叠加模拟描边，但效果不如 `text-stroke` 精准

## 实现方案
```css
:root {
  --stroke-color: #00e5ff;
  --fill-color: #0f172a;
  --bg-color: #ffffff;
}

/* 方案 A：text-stroke + paint-order 保持字重 */
.bold-stroke {
  font-size: 64px;
  font-weight: 900;

  -webkit-text-stroke: 2px var(--stroke-color);
  paint-order: stroke fill; /* 关键：先描边后填充，字不变细 */
  color: var(--fill-color);
}

/* 方案 B：镂空文字（仅描边，无填充） */
.hollow-text {
  font-size: 64px;
  font-weight: 900;
  -webkit-text-stroke: 1.5px var(--stroke-color);
  color: transparent; /* 填充透明，只显示描边 */
}

/* 方案 C：text-shadow 多重描边兜底 */
.fallback-stroke {
  font-size: 64px;
  font-weight: 900;
  color: var(--fill-color);
  /* 8 方向投影模拟描边 */
  text-shadow:
    -1px -1px 0 var(--stroke-color),
    1px -1px 0 var(--stroke-color),
    -1px 1px 0 var(--stroke-color),
    1px 1px 0 var(--stroke-color),
    0 0 2px var(--stroke-color);
}

@media (prefers-color-scheme: dark) {
  :root {
    --fill-color: #f8fafc;
    --stroke-color: #60a5fa;
  }
}
```

## 执行步骤
1. 用 `-webkit-text-stroke: <宽> <色>` 给文字描边
2. 默认描边会盖住填充让字变细，加 `paint-order: stroke fill` 调整顺序
3. 想要镂空效果就把 `color: transparent`，只留描边轮廓
4. 不支持 `text-stroke` 的环境用 `text-shadow` 八方向投影兜底
5. 暗黑模式只切换 CSS 变量

## 兼容性
- Chrome: 4+（`-webkit-` 前缀）
- Firefox: 49+（`-webkit-` 前缀兼容）
- Safari: 4+（`-webkit-` 前缀）
- `paint-order`: Chrome 35+、Firefox 60+、Safari 8+

## 降级方案
```css
@supports not (-webkit-text-stroke: 1px black) {
  .bold-stroke {
    /* 降级为多重 text-shadow */
    text-shadow:
      -1px -1px 0 var(--stroke-color),
      1px -1px 0 var(--stroke-color),
      -1px 1px 0 var(--stroke-color),
      1px 1px 0 var(--stroke-color);
    -webkit-text-stroke: 0;
  }
}
```
