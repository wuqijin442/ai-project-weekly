# 📂 选择器 · MOC

> CSS 选择器是精准控制元素的能力基石。现代选择器（`:has()`/`:is()`/`:where()`/`@layer`）让原本需要 JS 的逻辑用纯 CSS 实现。
> 核心原则：选择器嵌套不超 3 层；优先用 `:is()`/`:where()` 简化长选择器；用 `@layer` 管控第三方样式优先级。

## ⚡ 使用红线

1. `:has()` 性能：避免在长列表深层嵌套使用，浏览器需回溯检查
2. `:is()` 取最高特异性，可能比预期更高，注意覆盖问题
3. `:where()` 永远零特异性，适合做 reset 不影响后续覆盖
4. `@layer` 顺序：声明顺序决定优先级，后声明的层优先级更高
5. 选择器嵌套深度严格不超过 3 层，超长选择器用 `:is()` 拍平
