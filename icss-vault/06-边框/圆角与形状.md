# 圆角与形状

## 问题/场景
普通圆角用 `border-radius: 8px` 即可，但需要椭圆角、不对称圆角、水滴形、叶子形、胶囊形时，`border-radius` 的多值语法能创造各种形状，无需 `clip-path`，性能更好且支持动画。

## 核心原理
`border-radius` 是四个角的圆角半径简写，完整语法支持 **8 个值**（每角水平/垂直半径分开）：

```css
border-radius: 左上水平 右上水平 右下水平 左下水平 / 左上垂直 右上垂直 右下垂直 左下垂直;
```

**取值类型**：
- `px`：固定像素，不随尺寸变化
- `%`：基于元素对应边尺寸，响应式（`50%` 即椭圆/圆形）
- 混用：`border-radius: 50% 50% 50% 50% / 60% 60% 40% 40%`

**关键规律**：
- 单值 `8px`：四角相同
- 两值 `8px 16px`：左上右下 8px、右上左下 16px
- 四值 `8px 16px 24px 32px`：左上、右上、右下、左下（顺时针）
- `50%`：正方形→圆形，长方形→椭圆
- 斜杠 `/` 分隔水平与垂直半径，做椭圆角

**模拟形状原理**：通过让某角的水平/垂直半径差异极大（如 `100% 0 0 100%`），让边框「塌陷」成曲线，模拟水滴、叶子等有机形状。

## 实现方案

```css
:root {
  --color-primary: #1890ff;
  --color-card-bg: #ffffff;
}

/* 场景一：胶囊形（两端半圆） */
.capsule {
  width: 200px;
  height: 48px;
  border-radius: 999px;           /* 大于 height/2 即可，常用 999px */
  background: var(--color-primary);
}

/* 场景二：正圆 */
.circle {
  width: 100px;
  height: 100px;
  border-radius: 50%;             /* 正方形 + 50% = 正圆 */
}

/* 场景三：椭圆 */
.ellipse {
  width: 200px;
  height: 120px;
  border-radius: 50%;             /* 长方形 + 50% = 椭圆 */
}

/* 场景四：不对称圆角（某角特别大） */
.asymmetric {
  width: 200px;
  height: 120px;
  background: var(--color-primary);
  border-radius: 16px 16px 80px 16px;  /* 右下角特别大 */
}

/* 场景五：椭圆角（水平垂直半径不同） */
.ellipse-corners {
  width: 200px;
  height: 120px;
  background: var(--color-primary);
  /* 四角水平 40px、垂直 20px，呈椭圆角 */
  border-radius: 40px / 20px;
}

/* 场景六：水滴形 */
.water-drop {
  width: 100px;
  height: 100px;
  background: var(--color-primary);
  /* 左上 100% 让顶部塌成尖角，其余角圆角 */
  border-radius: 100% 0 100% 100% / 100% 0 100% 100%;
  transform: rotate(-45deg);      /* 旋转让尖角朝上 */
}

/* 场景七：叶子形 */
.leaf {
  width: 120px;
  height: 120px;
  background: var(--color-primary);
  /* 两对角 100%，形成叶子尖端 */
  border-radius: 0 100% 0 100%;
  transform: rotate(-45deg);
}

/* 场景八：扇形（四分之一圆） */
.sector {
  width: 100px;
  height: 100px;
  background: var(--color-primary);
  border-radius: 100% 0 0 0;      /* 仅左上角大圆角 */
}

/* 场景九：圆角动画（hover 变形） */
.morph-card {
  width: 200px;
  height: 120px;
  background: var(--color-primary);
  border-radius: 16px;
  transition: border-radius 0.4s cubic-bezier(0.4, 0, 0.2, 1);
}
.morph-card:hover {
  border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%;  /* 有机不规则形 */
}

/* 场景十：暗黑模式 */
@media (prefers-color-scheme: dark) {
  :root {
    --color-primary: #177ddc;
    --color-card-bg: #1f1f1f;
  }
}
```

## 执行步骤
1. 胶囊形：`border-radius: 999px`，只要值 ≥ height/2 就是两端半圆
2. 正圆：正方形 + `border-radius: 50%`；椭圆：长方形 + `50%`
3. 不对称圆角：四值顺时针 `左上 右上 右下 左下`，让某角特别大产生视觉焦点
4. 椭圆角：用 `/` 分隔，`border-radius: 40px / 20px` 让四角水平 40px、垂直 20px
5. 水滴形：`border-radius: 100% 0 100% 100%` 让左上塌成尖角，旋转 -45° 让尖朝上
6. 叶子形：两对角 `100%`（`0 100% 0 100%`），形成两端尖的叶子
7. 扇形：仅一角大圆角 `100% 0 0 0`，得到四分之一圆
8. 圆角动画：`transition: border-radius`，hover 时变成不规则有机形状（blob 形）

## 兼容性
- `border-radius`：Chrome 1+、Firefox 1+、Safari 3+、IE9+ 全面支持
- 8 值语法（`/` 分隔）：所有现代浏览器全面支持
- `%` 单位：全面支持
- 移动端：所有浏览器全面支持，无兼容顾虑
- 性能：`border-radius` 动画性能优于 `clip-path`，优先用 border-radius 做形状

## 降级方案
```css
/* border-radius 支持极广，几乎无需降级；仅 IE8 及以下不支持 */
/* 老旧浏览器用图片圆角或忽略圆角 */

/* 复杂形状（水滴/叶子）不支持时退回普通圆角 */
@supports not (border-radius: 100% 0 100% 100%) {
  .water-drop {
    border-radius: 50%;           /* 退回普通圆 */
  }
  .leaf {
    border-radius: 8px;           /* 退回普通圆角矩形 */
  }
}

/* 动画降级：不支持 transition border-radius 时直接切换 */
@supports not (transition: border-radius) {
  .morph-card:hover {
    border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%;
  }
}
```
