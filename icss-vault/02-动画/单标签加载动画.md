# 单标签加载动画

## 问题/场景
Loading 动画是页面加载/请求中必备的视觉反馈。传统实现常需要多个 DOM 标签嵌套（外圈+内圈+点），但 iCSS 风格推崇「单标签极致方案」——仅用一个 `<div>` 配合伪元素、`box-shadow` 多重边框、`conic-gradient` 实现复杂 loading 效果，HTML 更简洁。

## 核心原理
- **box-shadow 多重边框**：单个 `box-shadow` 可叠加多个阴影，配合 `animation` 让多个「圆点」同步旋转
- **conic-gradient + mask**：锥形渐变绘制环形进度，`mask` 镂空中心
- **伪元素**：`::before`/`::after` 各自带一层动画，主元素再带一层，单标签实现三层动画叠加

## 实现方案
```css
:root {
  --color-primary: #5e6ad2;
  --color-secondary: #a8b1ff;
  --size: 40px;
  --duration: 1s;
  --ease: cubic-bezier(0.4, 0, 0.2, 1);
}

/* ① 单标签旋转圈：conic-gradient + mask 镂空 */
.c-loading-ring {
  width: var(--size);
  height: var(--size);
  border-radius: 50%;
  background: conic-gradient(transparent 0deg, var(--color-primary) 360deg);
  -webkit-mask: radial-gradient(transparent calc(50% - 3px), #000 calc(50% - 2px));
          mask: radial-gradient(transparent calc(50% - 3px), #000 calc(50% - 2px));
  animation: spin var(--duration) linear infinite;
}
@keyframes spin {
  to { transform: rotate(360deg); }
}

/* ② 三点 loading：单标签 + box-shadow 多重 */
.c-loading-dots {
  width: 8px;
  height: 8px;
  border-radius: 50%;
  background: var(--color-primary);
  box-shadow:
    -16px 0 var(--color-secondary),                /* 左点 */
    16px 0 var(--color-secondary);                 /* 右点 */
  animation: dotsPulse var(--duration) var(--ease) infinite alternate;
}
@keyframes dotsPulse {
  0%   { box-shadow: -16px 0 var(--color-secondary), 16px 0 var(--color-secondary); }
  50%  { box-shadow: -16px 0 var(--color-primary),   16px 0 var(--color-secondary); }
  100% { box-shadow: -16px 0 var(--color-secondary), 16px 0 var(--color-primary); }
}

/* ③ 双圈反向旋转：伪元素叠加 */
.c-loading-double {
  position: relative;
  width: var(--size);
  height: var(--size);
}
.c-loading-double::before,
.c-loading-double::after {
  content: "";
  position: absolute;
  inset: 0;
  border-radius: 50%;
  border: 2px solid transparent;
}
.c-loading-double::before {
  border-top-color: var(--color-primary);
  border-right-color: var(--color-primary);
  animation: spin 0.8s linear infinite;
}
.c-loading-double::after {
  border-bottom-color: var(--color-secondary);
  border-left-color: var(--color-secondary);
  animation: spin 1.2s linear infinite reverse;   /* 反向旋转 */
}

/* ④ 进度条 loading：单标签 + 伪元素 */
.c-loading-bar {
  width: 120px;
  height: 4px;
  background: rgba(94, 106, 210, 0.2);
  border-radius: 2px;
  overflow: hidden;
  position: relative;
}
.c-loading-bar::after {
  content: "";
  position: absolute;
  inset: 0;
  width: 40%;
  background: var(--color-primary);
  border-radius: inherit;
  animation: barSlide 1.2s var(--ease) infinite;
}
@keyframes barSlide {
  0%   { transform: translateX(-100%); }
  100% { transform: translateX(350%); }
}

/* ⑤ 五彩旋转：conic-gradient 多色 */
.c-loading-rainbow {
  width: var(--size);
  height: var(--size);
  border-radius: 50%;
  background: conic-gradient(
    var(--color-primary),
    var(--color-secondary),
    #ff6b6b,
    #feca57,
    var(--color-primary)
  );
  -webkit-mask: radial-gradient(transparent calc(50% - 3px), #000 calc(50% - 2px));
          mask: radial-gradient(transparent calc(50% - 3px), #000 calc(50% - 2px));
  animation: spin 1.5s linear infinite;
}
```

## 执行步骤
1. **旋转圈方案**：用 `conic-gradient(transparent 0, color 360)` 绘制渐变圆，`mask: radial-gradient` 镂空中心成环形
2. **三点方案**：主元素 + 两个 `box-shadow` 偏移构成三点，动画修改 `box-shadow` 颜色实现脉冲
3. **双圈方案**：`::before`/`::after` 各画半圈边框，一个正向旋转、一个反向旋转，视觉层次丰富
4. **进度条方案**：父容器圆角+overflow:hidden，伪元素 40% 宽度横向滑动
5. **彩虹方案**：`conic-gradient` 多色 + `mask` 镂空 + `spin` 旋转
6. 所有方案仅用一个 `<div>`，HTML 极致简洁

## 兼容性
- Chrome: 53+（mask 需 120+ 去掉前缀）
- Firefox: 53+
- Safari: 15.4+（mask 之前需 `-webkit-`）
- `conic-gradient`: Chrome 69+, Firefox 83+, Safari 12.1+

## 降级方案
```css
/* 不支持 conic-gradient 时降级到 border 旋转 */
@supports not (background: conic-gradient(red, blue)) {
  .c-loading-ring {
    background: transparent;
    border: 3px solid var(--color-secondary);
    border-top-color: var(--color-primary);
    border-radius: 50%;
    -webkit-mask: none;
            mask: none;
  }
}

/* 不支持 mask 时降级到双层 div */
@supports not (mask: radial-gradient(transparent 50%, #000 50%)) {
  @supports not (-webkit-mask: radial-gradient(transparent 50%, #000 50%)) {
    .c-loading-ring {
      background: transparent;
      border: 3px solid var(--color-secondary);
      border-top-color: var(--color-primary);
      border-radius: 50%;
    }
  }
}

/* prefers-reduced-motion：禁用旋转 */
@media (prefers-reduced-motion: reduce) {
  .c-loading-ring,
  .c-loading-double::before,
  .c-loading-double::after,
  .c-loading-rainbow {
    animation: none;
  }
}
```
