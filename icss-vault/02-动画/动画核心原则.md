# 动画核心原则

## 问题/场景
糟糕的动画会让页面卡顿、跳帧、耗电。优秀动画的关键不是炫酷效果，而是性能——保证 60fps（每帧 16ms）流畅播放。核心原则：**仅对 `transform` 和 `opacity` 做动画**，避免触发重排（layout）和重绘（paint）。

## 核心原理
浏览器渲染流程：JS → Style → Layout（重排）→ Paint（重绘）→ Composite（合成）。重排开销最大，重绘次之，合成最快。

- **transform/opacity**：仅触发 Composite 阶段，GPU 加速，性能最佳
- **width/height/top/left**：触发 Layout，整页重新计算位置，最差
- **background/color**：触发 Paint，重绘像素，中等开销

`will-change` 提前告知浏览器即将变化的属性，让浏览器预先创建图层、准备 GPU 加速。但**不能滥用**，常驻 `will-change` 会占用大量内存。

## 实现方案
```css
:root {
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);     /* 减速缓动 */
  --ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);   /* 标准缓动 */
  --duration-fast: 0.2s;
  --duration-base: 0.3s;
  --duration-slow: 0.5s;
}

/* ✅ 推荐：仅动画 transform/opacity */
.c-card {
  transition: transform var(--duration-base) var(--ease-out),
              opacity var(--duration-base) var(--ease-out);
  will-change: transform;                /* 动画前预设 */
}
.c-card:hover {
  transform: translateY(-4px);           /* 仅 transform */
}
.c-card.is-leaving {
  /* 动画结束后立即移除 will-change（用 JS） */
}

/* ✅ 进入视口时启用 will-change，离开后移除 */
.c-card.is-animating {
  will-change: transform, opacity;
}

/* ❌ 反例：触发重排 */
.c-bad {
  transition: width 0.3s, top 0.3s, margin 0.3s;  /* 禁止 */
}

/* ✅ 修正：用 transform 替代 */
.c-good {
  transition: transform 0.3s var(--ease-out);
}
.c-good:hover {
  transform: translateX(100px) scale(1.05);  /* 替代 left/width */
}

/* ✅ 动画时长规范：0.2s-0.5s */
.c-duration-fast  { transition-duration: 0.2s; }  /* 微交互 */
.c-duration-base  { transition-duration: 0.3s; }  /* 常规 */
.c-duration-slow  { transition-duration: 0.5s; }  /* 大幅变化 */

/* ✅ cubic-bezier 缓动优于 ease/linear */
.c-ease-bounce {
  transition: transform 0.4s cubic-bezier(0.34, 1.56, 0.64, 1);  /* 回弹 */
}

/* ✅ contain 隔离：限制重排范围 */
.c-isolated {
  contain: layout paint;                  /* 隔离布局与重绘 */
  content-visibility: auto;               /* 视口外不渲染 */
}
```

## 执行步骤
1. 任何动画优先考虑 `transform`（位移/缩放/旋转）和 `opacity`（透明度）
2. 位移用 `translate` 替代 `top/left`，缩放用 `scale` 替代 `width/height`
3. 动画前给元素加 `will-change: transform`，提示浏览器预创建图层
4. 动画结束后**立即移除** `will-change`（用 JS 监听 `transitionend`/`animationend`）
5. 动画时长控制在 0.2s-0.5s：微交互 0.2s、常规 0.3s、大幅变化 0.5s
6. 缓动函数优先 `cubic-bezier`，避免 `linear`（机械感）和 `ease`（默认值不精致）
7. 长列表用 `contain: layout paint` + `content-visibility: auto` 隔离重排范围

## 兼容性
- `transform`/`opacity` 动画：全浏览器
- `will-change`: Chrome 36+, Firefox 36+, Safari 9+
- `contain`: Chrome 52+, Firefox 69+, Safari 15.4+
- `content-visibility`: Chrome 85+, Firefox 125+, Safari 18+

## 降级方案
```css
/* 不支持 will-change 时降级到 transformZ 触发硬件加速 */
@supports not (will-change: transform) {
  .c-card {
    transform: translateZ(0);             /* 强制创建图层 */
  }
}

/* 不支持 contain 时降级到普通渲染 */
@supports not (contain: layout) {
  .c-isolated {
    /* 无隔离降级，性能略差但功能正常 */
  }
}

/* prefers-reduced-motion：尊重用户偏好，禁用动画 */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```
