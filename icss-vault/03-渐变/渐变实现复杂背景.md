# 渐变实现复杂背景

## 问题/场景
网格背景、点阵、噪点纹理、几何图案——传统方案用图片资源，体积大且不可缩放。多层渐变叠加能纯 CSS 实现矢量图案，零图片请求、无限缩放无锯齿、颜色可变量化管理。

## 核心原理
CSS `background` 支持多层叠加，先写的在上层。通过组合 `linear-gradient`（线条）、`radial-gradient`（圆点）、`repeating-*`（重复图案），配合 `background-size`/`background-position` 控制每层尺寸位置，可拼出任意复杂图案。

**关键技巧**：
- 网格 = 水平线 + 垂直线双层 linear-gradient
- 点阵 = radial-gradient 小圆点 + background-size 平铺
- 几何图案 = repeating-linear-gradient 多层错位

## 实现方案
```css
:root {
  --color-line: rgba(94, 106, 210, 0.1);
  --color-line-strong: rgba(94, 106, 210, 0.3);
  --color-dot: rgba(94, 106, 210, 0.4);
  --color-bg: #fff;
  --grid-size: 20px;
}

/* ① 网格背景：双层 linear-gradient */
.c-grid {
  background:
    linear-gradient(var(--color-line) 1px, transparent 1px) 0 0 / var(--grid-size) var(--grid-size),
    linear-gradient(90deg, var(--color-line) 1px, transparent 1px) 0 0 / var(--grid-size) var(--grid-size);
  background-color: var(--color-bg);
}

/* ② 双层网格：主网格 + 强调网格 */
.c-grid-double {
  background:
    linear-gradient(var(--color-line-strong) 1px, transparent 1px) 0 0 / 100px 100px,
    linear-gradient(90deg, var(--color-line-strong) 1px, transparent 1px) 0 0 / 100px 100px,
    linear-gradient(var(--color-line) 1px, transparent 1px) 0 0 / 20px 20px,
    linear-gradient(90deg, var(--color-line) 1px, transparent 1px) 0 0 / 20px 20px;
  background-color: var(--color-bg);
}

/* ③ 点阵背景：radial-gradient 小圆点 */
.c-dots {
  background: radial-gradient(var(--color-dot) 1px, transparent 1px) 0 0 / 20px 20px;
  background-color: var(--color-bg);
}

/* ④ 棋盘格：repeating-conic-gradient */
.c-checkerboard {
  background: repeating-conic-gradient(
    var(--color-line) 0 25%,
    transparent 0 50%
  ) 0 0 / 20px 20px;
  background-color: var(--color-bg);
}

/* ⑤ 对角条纹 + 网格组合 */
.c-stripes-grid {
  background:
    linear-gradient(45deg, var(--color-line) 25%, transparent 25%, transparent 75%, var(--color-line) 75%) 0 0 / 40px 40px,
    linear-gradient(45deg, var(--color-line) 25%, transparent 25%, transparent 75%, var(--color-line) 75%) 20px 20px / 40px 40px;
  background-color: var(--color-bg);
}

/* ⑥ 噪点纹理：SVG 滤镜 inline */
.c-noise {
  background:
    url("data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='200' height='200'><filter id='n'><feTurbulence type='fractalNoise' baseFrequency='0.9'/></filter><rect width='100%' height='100%' filter='url(%23n)' opacity='0.4'/></svg>");
}

/* ⑦ 渐变光晕背景：多层 radial */
.c-glow-bg {
  background:
    radial-gradient(circle at 20% 30%, rgba(94, 106, 210, 0.15), transparent 50%),
    radial-gradient(circle at 80% 70%, rgba(255, 107, 107, 0.1), transparent 50%),
    radial-gradient(circle at 50% 50%, rgba(168, 177, 255, 0.08), transparent 60%);
  background-color: var(--color-bg);
}

/* ⑧ 三角形图案：linear-gradient + 旋转 */
.c-triangles {
  background:
    linear-gradient(60deg, var(--color-line) 25%, transparent 25.5%, transparent 75%, var(--color-line) 75%) 0 0 / 40px 70px,
    linear-gradient(120deg, var(--color-line) 25%, transparent 25.5%, transparent 75%, var(--color-line) 75%) 0 0 / 40px 70px;
  background-color: var(--color-bg);
}

/* ⑨ 动态背景：渐变位置动画 */
.c-animated-bg {
  background:
    linear-gradient(45deg, var(--color-line), transparent) 0 0 / 100% 100%,
    linear-gradient(-45deg, var(--color-line), transparent) 0 0 / 100% 100%;
  background-color: var(--color-bg);
  animation: bgShift 20s linear infinite;
}
@keyframes bgShift {
  0%   { background-position: 0 0, 0 0; }
  100% { background-position: 100px 100px, -100px 100px; }
}

/* ⑩ 暗黑模式：低对比背景 */
@media (prefers-color-scheme: dark) {
  :root {
    --color-line: rgba(139, 149, 255, 0.08);
    --color-line-strong: rgba(139, 149, 255, 0.2);
    --color-dot: rgba(139, 149, 255, 0.2);
    --color-bg: #1a1d2e;
  }
}
```

## 执行步骤
1. 网格背景：水平线 `linear-gradient` + 垂直线 `linear-gradient(90deg, ...)` 双层叠加
2. 每层用 `background-size` 控制网格单元大小（如 `20px 20px`）
3. 点阵背景：`radial-gradient(色 1px, transparent 1px)` + `background-size` 平铺
4. 棋盘格：`repeating-conic-gradient(色 0 25%, transparent 0 50%)` + `background-size`
5. 噪点纹理：inline SVG `feTurbulence` 滤镜，无需外部图片
6. 多层光晕：多个 `radial-gradient` 在不同位置叠加，营造氛围感
7. 动态背景：用 `background-position` 动画移动图案
8. 所有颜色用 CSS 变量管理，暗黑模式只改变量值，确保对比度达标

## 兼容性
- 多层 background：Chrome 26+, Firefox 16+, Safari 6.1+
- `background-size`：全浏览器
- inline SVG：全浏览器
- `repeating-conic-gradient`：Chrome 69+, Firefox 83+, Safari 12.1+

## 降级方案
```css
/* 不支持多层 background 时降级到单层 */
@supports not (background: linear-gradient(red, blue), linear-gradient(blue, red)) {
  .c-grid {
    background: var(--color-bg);
    background-image: linear-gradient(var(--color-line) 1px, transparent 1px);
    background-size: var(--grid-size) var(--grid-size);
  }
}

/* 不支持 SVG inline 时降级到纯色 */
@supports not (background: url("data:image/svg+xml,...")) {
  .c-noise {
    background: var(--color-bg);
  }
}

/* 不支持 repeating-conic-gradient 时降级到 linear-gradient 平铺棋盘 */
@supports not (background: repeating-conic-gradient(red, blue)) {
  .c-checkerboard {
    background:
      linear-gradient(45deg, var(--color-line) 25%, transparent 25%) 0 0 / 20px 20px,
      linear-gradient(-45deg, var(--color-line) 25%, transparent 25%) 0 0 / 20px 20px,
      linear-gradient(45deg, transparent 75%, var(--color-line) 75%) 0 0 / 20px 20px,
      linear-gradient(-45deg, transparent 75%, var(--color-line) 75%) 0 0 / 20px 20px;
    background-color: var(--color-bg);
  }
}

/* prefers-reduced-motion：禁用动态背景 */
@media (prefers-reduced-motion: reduce) {
  .c-animated-bg {
    animation: none;
  }
}
```
