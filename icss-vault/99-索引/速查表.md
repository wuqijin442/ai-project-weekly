## 🎓 常用模式组合

### 卡片悬浮增强

```css
.card {
  transition: transform 0.3s var(--ease), box-shadow 0.3s var(--ease);
  contain: layout paint;
}
.card:hover {
  will-change: transform;
  transform: translateY(-4px);
  box-shadow: 0 8px 32px rgba(0,0,0,0.1);
}
```

### 容器响应式卡片

```css
.grid { container-type: inline-size; display: grid; gap: 16px; grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); }
.card { font-size: clamp(0.875rem, 4cqi, 1.125rem); }
@container (min-width: 600px) {
  .card { display: grid; grid-template-columns: 1fr 2fr; }
}
```

### Tooltip 完整方案

```css
.btn { anchor-name: --t; }
.tooltip {
  position: fixed; position-anchor: --t;
  top: anchor(--t bottom); left: anchor(--t center);
  transform: translate(-50%, 8px);
  position-try-fallbacks: flip-block;
}
```

### 液态玻璃卡片

```css
.glass {
  backdrop-filter: blur(10px) url(#liquid-glass);
  background: rgba(255,255,255,0.1);
  border: 1px solid rgba(255,255,255,0.2);
  box-shadow: inset 0 1px 0 rgba(255,255,255,0.4);
}
```

### 可动画颜色变量

```css
@property --hue { syntax: '<number>'; inherits: false; initial-value: 180; }
.box {
  background: hsl(var(--hue), 70%, 50%);
  transition: --hue 0.5s;
}
.box:hover { --hue: 540; }
```
