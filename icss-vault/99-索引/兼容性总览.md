# 📊 兼容性总览

> 各 CSS 特性在主流浏览器的最低支持版本，按兼容性分级（现代/渐进/实验），并给出降级方案链接。

## 兼容性分级标准

| 等级 | 含义 | 生产建议 |
|------|------|----------|
| 🟢 现代 | Chrome/Firefox/Safari 全支持 | 直接使用 |
| 🟡 渐进 | 部分支持，少数缺失 | 带 `@supports` 降级 |
| 🔴 实验 | 仅 Chrome/Edge 支持 | 渐进增强，必备降级 |

## 降级方案速查

### 常用降级模式

```css
/* 模式 1：@supports 特性检测 */
@supports (特性: 值) {
  /* 现代写法 */
}
@supports not (特性: 值) {
  /* 降级写法 */
}

/* 模式 2：渐进增强（先写基础，再叠加） */
.element {
  /* 基础样式（全兼容） */
  background: rgba(0, 0, 0, 0.5);
}
@supports (backdrop-filter: blur(10px)) {
  .element {
    backdrop-filter: blur(10px);  /* 叠加增强 */
  }
}

/* 模式 3：优雅降级（先写现代，再降级） */
.element {
  backdrop-filter: blur(10px);  /* 现代浏览器 */
}
@supports not (backdrop-filter: blur(10px)) {
  .element {
    background: rgba(0, 0, 0, 0.8);  /* 老浏览器加深背景 */
  }
}
```

### 按场景的降级方案

| 场景 | 现代方案 | 降级方案 | 笔记 |
|------|----------|----------|------|
| 长列表渲染 | `content-visibility: auto` | JS 虚拟列表 | [[content-visibility]] |
| Tooltip 定位 | `anchor()` + `position-anchor` | JS `getBoundingClientRect` | [[Anchor-Positioning-锚点定位]] |
| 边界翻转 | `@position-try` | floating-ui JS 库 | [[position-try-智能边界]] |
| 多 transform 动画 | `animation-composition: accumulate` | 多层 div 嵌套 | [[animation-composition-动画合成]] |
| 滚动驱动动画 | `animation-timeline: scroll()` | JS scroll 监听 | [[路径动画×滚动驱动]] |
| 状态过渡 | `view-transition-name` | FLIP + JS | [[View-Transitions-API]] |
| 液态玻璃 | `backdrop-filter: url()` | `backdrop-filter: blur()` | [[Liquid-Glass-液态玻璃]] |
| 可动画变量 | `@property` | 直接动画属性 | [[CSS-Houdini]] |
| 自定义绘制 | Paint API | SVG/PNG 背景 | [[CSS-Houdini]] |
| 子网格对齐 | `subgrid` | 复制父列宽定义 | [[subgrid-子网格]] |
| 作用域隔离 | `@scope` | BEM 命名 | [[scope-作用域]] |
| 圆周运动 | `sin()`/`cos()` | 父容器旋转 + 子反向 | [[CSS三角函数]] |

## 决策树

```
要用的特性在表中查到 →
├─ 🟢 现代 → 直接用，无需降级
├─ 🟡 渐进 →
│   ├─ 核心功能？→ 必须降级
│   └─ 体验增强？→ 可不降级，老浏览器无该效果
└─ 🔴 实验 →
    ├─ 核心功能？→ 不建议用，换方案
    └─ 体验增强？→ 用，必带降级
```
