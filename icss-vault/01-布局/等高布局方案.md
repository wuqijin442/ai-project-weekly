# 等高布局方案

## 问题/场景
卡片墙、商品列表、特性对比等场景需要多列视觉等高，但内容长度不一致时高度参差不齐。历史上需要 `display: table-cell` 或 `padding + margin` 负值 hack，现代 Flex/Grid 已天然支持等高，但了解历史方案有助于维护老代码。

## 核心原理
- **Flex**：默认 `align-items: stretch`，子项在交叉轴方向自动拉伸至最高项高度
- **Grid**：默认 `align-items: stretch`，同行 grid item 自动等高
- **table-cell**：表格单元格天然同行等高，是兼容性最好的方案
- **padding+margin 负值**：人为撑大高度再用负 margin 抵消，配合 `overflow: hidden` 容器裁剪

## 实现方案
```css
:root {
  --gap-md: 16px;
  --color-border: #eee;
  --max-height: 9999px;
}

/* ① Flex 天然等高：现代方案首选 */
.c-flex-equal {
  display: flex;
  align-items: stretch;                   /* 默认值，可省略 */
  gap: var(--gap-md);
}
.c-flex-equal__item {
  flex: 1;
  display: flex;
  flex-direction: column;
}
.c-flex-equal__btn {
  margin-top: auto;                       /* 按钮推到底部 */
}

/* ② Grid 天然等高 */
.c-grid-equal {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  align-items: stretch;                   /* 默认值 */
  gap: var(--gap-md);
}

/* ③ table-cell 方案：兼容老浏览器 */
.c-table-equal {
  display: table;
  width: 100%;
  border-collapse: separate;
  border-spacing: var(--gap-md) 0;
}
.c-table-equal__item {
  display: table-cell;
  vertical-align: top;
  border: 1px solid var(--color-border);
}

/* ④ padding + margin 负值 hack：历史方案 */
.c-hack-equal {
  display: flex;
  gap: var(--gap-md);
  overflow: hidden;                       /* 裁剪超出的 padding */
}
.c-hack-equal__item {
  flex: 1;
  padding-bottom: var(--max-height);      /* 人为撑大 */
  margin-bottom: calc(-1 * var(--max-height));  /* 负值抵消 */
}
```

## 执行步骤
1. 优先用 Flex 或 Grid，`align-items: stretch` 是默认值，无需额外声明
2. 卡片内部用 `flex-direction: column` + `margin-top: auto` 让按钮固定在底部
3. 老浏览器兼容场景用 `display: table-cell`，配合 `vertical-align: top`
4. 历史 hack 方案：每个子项加超大 `padding-bottom`，再用等量负 `margin-bottom` 抵消
5. 父容器加 `overflow: hidden` 裁剪 hack 造成的空白
6. hack 方案会裁剪子项底部的阴影/边框，慎用

## 兼容性
- Flex/Grid 方案：Chrome 29+/57+, Firefox 28+/52+, Safari 9+/10.1+
- table-cell 方案：全浏览器兼容
- padding+margin hack：全浏览器兼容

## 降级方案
```css
/* Flex 不支持时降级到 table-cell */
@supports not (display: flex) {
  .c-flex-equal {
    display: table;
    width: 100%;
  }
  .c-flex-equal__item {
    display: table-cell;
    vertical-align: top;
  }
}

/* Grid 不支持时降级到 Flex */
@supports not (display: grid) {
  .c-grid-equal {
    display: flex;
    flex-wrap: wrap;
  }
  .c-grid-equal > * {
    flex: 1 1 33.33%;
  }
}
```
