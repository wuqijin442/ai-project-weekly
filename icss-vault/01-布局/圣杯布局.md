# 圣杯布局

## 问题/场景
经典三栏布局：两侧边栏定宽，中间主区域自适应，且主区域 HTML 顺序在前（优先渲染）。历史上圣杯布局、双飞翼布局是 float 时代的解法，现代 Grid 让三栏布局只需几行声明。

## 核心原理
- **圣杯布局**：父容器 padding 留出两侧空间，三栏全部 float，主区域宽度 100%，左右栏用 `margin` 负值 + `position: relative` 偏移到 padding 空间
- **双飞翼布局**：圣杯的优化版，主区域内部再加一层容器，避免使用 relative，兼容性更好
- **现代 Grid**：用 `grid-template-columns: 200px 1fr 200px` 或 `grid-template-areas` 命名区域，几行解决

## 实现方案
```css
:root {
  --gap-md: 16px;
  --sidebar-w: 200px;
  --aside-w: 200px;
  --color-border: #eee;
}

/* ============= 方案一：现代 Grid（推荐） ============= */
.c-holy-grail--grid {
  display: grid;
  grid-template:
    "header header header" auto
    "sidebar main  aside"  1fr
    "footer footer footer" auto
    / var(--sidebar-w) 1fr var(--aside-w);
  gap: var(--gap-md);
  min-height: 100vh;
}
.c-holy-grail--grid > header { grid-area: header; }
.c-holy-grail--grid > .sidebar { grid-area: sidebar; }
.c-holy-grail--grid > .main { grid-area: main; min-width: 0; }
.c-holy-grail--grid > .aside { grid-area: aside; }
.c-holy-grail--grid > footer { grid-area: footer; }

/* ============= 方案二：Flex 实现 ============= */
.c-holy-grail--flex {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
.c-holy-grail--flex > .body {
  display: flex;
  flex: 1;
  gap: var(--gap-md);
}
.c-holy-grail--flex > .body > .main {
  flex: 1;
  min-width: 0;
  order: 2;                               /* 主区域视觉居中 */
}
.c-holy-grail--flex > .body > .sidebar { width: var(--sidebar-w); order: 1; }
.c-holy-grail--flex > .body > .aside  { width: var(--aside-w);   order: 3; }

/* ============= 方案三：经典圣杯（float + padding） ============= */
.c-holy-grail--classic {
  padding: 0 var(--aside-w) 0 var(--sidebar-w);  /* 两侧留白 */
  overflow: hidden;                       /* 清除浮动 */
}
.c-holy-grail--classic > .main {
  float: left;
  width: 100%;
  min-height: 200px;
}
.c-holy-grail--classic > .sidebar,
.c-holy-grail--classic > .aside {
  float: left;
  width: var(--sidebar-w);
  min-height: 200px;
  position: relative;
}
.c-holy-grail--classic > .sidebar {
  margin-left: calc(-1 * var(--sidebar-w) - 100%);  /* 拉到左留白区 */
  left: calc(-1 * var(--sidebar-w));
}
.c-holy-grail--classic > .aside {
  width: var(--aside-w);
  margin-left: calc(-1 * var(--aside-w));         /* 拉到右留白区 */
  right: calc(-1 * var(--aside-w));
}

/* ============= 方案四：双飞翼（主区域多套一层） ============= */
.c-flying-wing {
  overflow: hidden;
}
.c-flying-wing > .main-wrap {
  float: left;
  width: 100%;
}
.c-flying-wing > .main-wrap > .main {
  margin: 0 var(--aside-w) 0 var(--sidebar-w);    /* 内层留白 */
}
.c-flying-wing > .sidebar,
.c-flying-wing > .aside {
  float: left;
  min-height: 200px;
}
.c-flying-wing > .sidebar {
  width: var(--sidebar-w);
  margin-left: -100%;                      /* 拉到最左 */
}
.c-flying-wing > .aside {
  width: var(--aside-w);
  margin-left: calc(-1 * var(--aside-w));  /* 拉到最右 */
}
```

## 执行步骤
1. 现代项目直接选 **Grid 方案**：用 `grid-template-areas` 命名区域可读性最高
2. 主区域加 `min-width: 0`，防止长内容撑破网格
3. Flex 方案用 `order` 控制视觉顺序，HTML 顺序仍可保持主区域在前
4. 经典圣杯/双飞翼仅用于维护老代码：父容器 padding 留白 + 三栏 float
5. 圣杯方案用 `position: relative` 偏移，双飞翼改用主区域内部 margin，避免定位
6. 移动端响应式：媒体查询中改为单列纵向布局

## 兼容性
- Grid 方案：Chrome 57+, Firefox 52+, Safari 10.1+
- Flex 方案：Chrome 29+, Firefox 28+, Safari 9+
- 经典圣杯/双飞翼：全浏览器兼容

## 降级方案
```css
/* Grid 不支持时降级到 Flex */
@supports not (display: grid) {
  .c-holy-grail--grid {
    display: flex;
    flex-direction: column;
  }
  .c-holy-grail--grid > .body {
    display: flex;
    flex: 1;
  }
  .c-holy-grail--grid > .main { flex: 1; }
  .c-holy-grail--grid > .sidebar,
  .c-holy-grail--grid > .aside { width: var(--sidebar-w); }
}

/* 移动端单列 */
@media (max-width: 768px) {
  .c-holy-grail--grid {
    grid-template:
      "header" auto
      "main"   1fr
      "sidebar" auto
      "aside"  auto
      "footer" auto
      / 1fr;
  }
}
```
